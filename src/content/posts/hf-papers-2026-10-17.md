## 二、研究背景与动机

Agentic RL（用在线 rollout + 奖励反馈训练 LLM 智能体做多轮推理和工具调用）近两年收益显著，但它有一个很少被摆上台面的隐含假设：**一条 rollout 就是一个会话**——上下文从头到尾连续累积，整条轨迹构成一个训练片段。

问题在于，现代智能体的推理侧早已不是单会话了：

- **上下文压缩（context compaction）**：上下文逼近窗口上限时把执行历史压缩成短前缀，后续动作的条件分布被改写，等于开启了一个新会话；
- **子智能体分叉（subagent forking）**：主智能体把子任务委派给子智能体，分出分支会话。

也就是说，**推理时执行的是多会话轨迹，训练时优化的却是单会话假设**。这个 train–inference mismatch 让多会话推理能力无法靠"单会话训练 + 测试时扩展"自然涌现——论文的实验明确验证了这一点（单会话 GRPO 训练的模型直接上多会话推理，收益远低于多会话训练）。

在多会话设置下，最自然的做法是 **broadcasting**：把轨迹级的最终优势复制给所有会话的所有 token。但这有两处硬伤：一是不区分各会话对最终结果的贡献（做得多的会话和划水的会话拿同样的信号）；二是不引导会话在轨迹内的**分配**（该在什么时候开新会话、开多少个，完全没被优化）。

于是问题变成：**如何把"最终结果"这个稀疏信号，合理地分配到"轨迹 → 会话"两级结构上？** 这正是信用分配（credit assignment）问题在智能体训练中的又一次显形。

## 三、核心方法与创新点

Mosaic 的全称是"无 critic 的层级优化"（critic-free hierarchical optimization），分两层设计。

### 3.1 轨迹层：会话感知的优势估计

先回顾 GRPO：优势完全由组内相对结果奖励决定。多会话设置下，轨迹的会话数 $N_i$ 携带额外信息——它是探索程度和结构复杂度的代理。但 $N_i$ 不能直接当奖励：原始尺度不可靠，而且偏好方向必须依赖任务结果（否则策略会学会"多开会话刷分"）。

Mosaic 用三条**排序约束**把直觉形式化：

- **C1**：成功轨迹里，会话越多成本越高，优势应越低；少会话完成任务的应得更高优势；
- **C2**：失败轨迹里，会话太少可能意味着探索不足，优势应更低；失败但做了更多会话尝试的应得更高优势；
- **C3**：结果奖励必须占主导——用更多会话不能让失败轨迹反超成功轨迹。

具体实现：先在按结果分的子群 $G_1$（成功）/ $G_0$（失败）内，把 $N_i$ 映射为**居中秩** $u_i = 2f(N_i) - 1 \in [-1,1]$（用秩而非原始会话数，对长尾轨迹更稳健），再用它调制原始优势：

$$\hat{A}_i^{sat} = (1 - \rho u_i)\,\hat{A}_i^{traj}$$

注意符号：$u_i$ 越大（会话越多）→ 调制因子越小。$\rho \in [0,1)$ 保证因子恒正，**只缩放不改号**——C3 天然成立。对于同质组（全成功或全失败，GRPO 优势为 0），还有 fallback 项：全成功组用 $-\beta_1 u_i$ 奖励省会话的轨迹；全失败组用 $\beta_0 \min(u_i, 0)$ 保守惩罚过度探索，保证没有失败轨迹拿到正优势。

### 3.2 会话层：按边际信息增益塑造优势

轨迹级优势再精细，同一条轨迹上所有会话仍共享同一个标量。Mosaic 把每个会话视为一次**状态转移** $s_{i,j}: v_{i,j-1} \to v_{i,j}$（状态 = 会话开始/结束时可见的前缀上下文），并区分三类会话：**普通会话**（推理 + 工具调用）、**压缩会话**（把长上下文压成短前缀）、**子智能体会话**（委派与结果回收）。

如何衡量一个会话转移的贡献？不需要训练 critic——用**答案似然势函数**：

$$\Phi_{\bar{\theta}}(y^*|x, v) = \frac{1}{L}\sum_{\ell=1}^{L} \log \pi_{\bar{\theta}}(y^*_{\ell} | x, v, y^*_{<\ell})$$

直觉：给定当前上下文 $v$，策略有多容易说出正确答案。一个会话若补充了有效证据、压缩掉噪声、或带回高质量子任务结果，这个对数似然就该上升。会话级奖励就是前后两个状态的势差（stop-gradient，用更新前的策略打分）：

$$r^\Delta_{i,j} = \Phi(y^*|x, v_{i,j}) - \Phi(y^*|x, v_{i,j-1})$$

两个关键细节：

1. **按会话类型分别归一化**（式 17）。不同类型会话的边际增益分布天然不同——普通会话靠检索获得证据，压缩会话靠保真，子智能体会话靠执行与交接质量。若做全局归一化，均值偏低的压缩会话会被系统性压低（消融实验观察到这一偏差）；按类型各自中心化后，每类都能拿到相对自身基线的正/负信号。
2. **最后一个会话置零**。末会话的输出状态通常包含最终答案，正确答案会骤然抬高似然、污染边际增益分布，所以把它的塑造信号设为 0。

最终每个会话的训练优势是两级信号的叠加：

$$\hat{A}_{i,j} = \hat{A}_i^{traj} + \lambda_r \hat{r}_{i,j}$$

第一项给长期的、结果导向的全局信号，第二项区分各会话的局部相对贡献。整体无 critic、无价值网络，仍是纯策略梯度。

### 3.3 创新点小结

- **把"多会话"确立为训练设置**：任意会话数的轨迹都能进统一算法，覆盖压缩与分叉两种主流机制；
- **会话用量进入优势**：通过 C1–C3 排序约束 + 居中秩调制，实现"够用就好"的会话预算，而不是盲目扩张；
- **免 critic 的过程监督**：用答案似然的边际信息增益做会话级信用分配，且按类型归一化消除分布偏差。

## 四、实验结果与分析

**设置**：基准为 BrowseComp（1,266 个需要深度联网检索的难题）；基座 Qwen3.5-4B + ReAct 循环，工具为 search（Serper）与 visit（Jina Reader），每会话 128K token；训练数据为 REDSearcher_RL_1k（1,000 条深度检索任务），训练 1 epoch，rollout batch 16 × 组大小 8；LLM judge 为 deepseek-v4-flash。超参：$\rho=0.2, \beta_0=0.1, \beta_1=0.2, \lambda_r=0.1$。

**主结果（BrowseComp 准确率 % / 平均会话数）**：

| 方法 | 单会话推理 | 多会话-压缩 | 多会话-子智能体 |
|------|-----------|-------------|----------------|
| Qwen3.5-4B（未训练） | 23.22 / 1.00 | 24.80 / 1.70 | 21.64 / 2.98 |
| 单会话 GRPO | 31.99 / 1.00 | 34.68 / 1.24 | 31.91 / 2.09 |
| IGPO（回合级边际增益） | 28.52 / 1.00 | 31.36 / 4.12 | 24.64 / 3.26 |
| 多会话 Broadcasting | — | 35.31 / 3.17 | 31.44 / 4.43 |
| **Mosaic** | — | **38.86 / 2.35** | **32.46 / 3.77** |

**关键发现**：

1. **多会话能力不会自然涌现**。单会话 GRPO 训练的模型拿到多会话推理，只涨到 34.68（压缩）/31.91（分叉），明显低于多会话训练的 Broadcasting 与 Mosaic——训练与推理的会话结构必须对齐。
2. **Mosaic 全面超过广播，且更省**。压缩场景 +3.55 点、分叉场景 +1.02 点，平均会话数反而更少（2.35 vs 3.17；3.77 vs 4.43）：不是靠多开会话，而是把会话花在刀刃上。
3. **显著优于 IGPO**。把边际增益放在回合级（IGPO）既慢又差；Mosaic 在会话级做，边际增益计算的 wall-time 大幅下降，性能反而更高——结构对了，粒度就重要了。
4. **消融**：两层组件单独使用都优于 Broadcasting；叠加在压缩场景（线性会话链）有明显额外增益，但在子智能体场景（会话影响呈 DAG 结构，一个会话可能影响多个下游会话）只有温和提升——边际增益是"一步近似"，在非线性结构下会低估长程贡献。
5. **机制分析**：混合结果组内，成功轨迹的优势大致随会话数递减、失败轨迹递增，且成功组整体更高——C1–C3 的排序意图被学到了；按类型归一化修复了全局归一化对压缩会话的系统性压制。
6. **会话行为画像**（Table 2）：Broadcasting 三项指标（会话数、有效增益会话占比、单位会话增益）全部上涨；Mosaic 则是**会话数不涨（2.35 vs 3.17），有效增益会话占比 59.92%（vs 47.74%）、单位会话增益 0.89（vs 0.86）双双提升**。作者由此提出一个很好的判断：多会话优化的核心问题不是"用多少个会话"，而是"从执行的每个会话里榨出多少有效进展"。

## 五、与智能体认知模块的关联

这篇论文对智能体认知架构研究有几条直接的启发：

- **记忆/上下文管理的训练闭环**：上下文压缩本是推理侧的记忆治理手段，但 Mosaic 说明它同时也是**训练时的信用分配单元**。压缩会话不是"无信息的过渡"，而是要被单独评估、单独给信号的"记忆巩固动作"。做智能体记忆研究的人可以从中学到：记忆操作的价值可以用"对正确答案似然的增益"来量化。
- **推理与规划**：会话预算的排序约束（C1/C2）实质上是把"何时继续探索、何时收手"的元决策编码进了优势函数。这与规划中的资源理性（bounded rationality）一脉相承：好的智能体不是开最多的线程，而是让每一步计算的边际价值为正。
- **多智能体/子智能体结构**：子智能体分叉的会话结构是 DAG，一步边际增益会低估长程贡献——这直接指向多智能体信用分配的经典难题，也解释了为何 Mosaic 在分叉场景增益较小。把 Shapley 值、反事实贡献等更精细的分配机制搬到会话层，是显而易见的下一步。
- **评估与基准**：论文把"会话质量"（有效增益会话占比、单位会话增益）作为独立的评估维度，提示我们评价长程智能体时，除了最终准确率，还应报告**计算的分配结构**——它比准确率更早暴露策略的退化（比如靠堆会话刷分）。

## 六、总结与启发

**亮点**：选题敏锐（抓住了推理侧技术演进与训练侧假设的错配）；方法干净（无 critic、两层优势、纯策略梯度，工程上易复用）；分析扎实（不仅给数字，还回答"为什么会涨"和"会话行为变成了什么样"）。尤其是"会话数不该涨而质量该涨"的画像分析，把一个 RL 结果讲成了对智能体计算分配的理解。

**不足**：① 规模较小——单基准（BrowseComp）、单模型（Qwen3.5-4B）、单 epoch，泛化性待验证；② 边际信息增益依赖 ground-truth 答案做势函数，训练需要标注答案，且用策略自身似然度量状态价值存在自指偏差；③ 子智能体场景的 DAG 结构下增益有限，说明一步边际贡献的近似是瓶颈；④ 会话数只是探索/成本的代理信号，与真实执行成本（token、时延）没有直接挂钩。

**对后续研究的启发**：多会话（乃至"会话结构可变"）应当成为 Agentic RL 的默认设置而非特例——凡是有压缩、分叉、恢复机制的智能体，训练目标都该感知会话结构。把"会话效用与分配"作为显式优化目标，而不是让它们作为副作用出现，可能是提升长程任务智能体样本效率的下一个杠杆。
