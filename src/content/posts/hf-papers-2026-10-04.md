# VISTA: A Visual Harness for Reasoning in an Interactive World —— 给多模态模型戴上"视觉外壳"

> **TL;DR**：VISTA 是一个"视觉外壳（visual harness）"——它让通用多模态模型**直接看**画面、维护一份**无损视觉记忆**、在推理过程中**主动检索并重新组织视觉输入**。在 ARC-AGI-3 上，VISTA 让 Claude Opus 5.0 的 RHAE 分数从 40.68 一路涨到满分 100，25 个公开游戏全通关，而且比人类首试**少用 57.4% 的动作**。更重要的是，这套极简的"外壳"能直接搬到其他视觉游戏基准上，横扫 GameWorld、AI GameStore、BabyVision 等多个测试集。它给出的启示是：**多模态模型的推理能力常常被糟糕的"输入管道"限制住了**，而不是模型本身不行。

## 二、研究背景与动机

### 2.1 为什么关注"交互式视觉推理"

人类在陌生环境中，靠的是**感知 → 推理 → 记忆 → 行动**的循环：看到画面、在脑中形成理解、回忆过去经验、做出动作、再观察。整个过程**高度视觉化**，且能跨长时间尺度保持连贯。

但现有 AI 智能体在类似场景下表现却很挣扎。作者选了一个典型的测试床——**ARC-AGI-3**：一组交互式视觉游戏，玩家（智能体）一开始不知道规则、不知道目标，只能通过试错从观察中**推断游戏机制**，然后在多个关卡中迁移这套理解。这要求长程视觉推理、状态跟踪、因果假设验证。

### 2.2 三种主流思路及其瓶颈

作者总结了当前做 ARC-AGI-3（以及类似交互式环境）的三条路，各有明显短板：

**(a) 语言智能体（图 1a）**：把画面转成文本/符号表示，丢给 LLM 推理。问题：**空间信息严重损失**，且文本 token 效率低。ARC-AGI-3 天然是 2D 空间推理，扁平化文本让模型丢失了"物体之间相对位置"这类关键视觉先验。

**(b) 符号程序方法**：让 LLM 写一个可执行的符号世界模型（程序），用程序模拟状态转移。这条路在 ARC-AGI-3 上取得了不错成绩，但**依赖程序合成能力**，泛化到其他视觉环境时常常需要重做工程。

**(c) 现有多模态智能体（图 1b）**：直接用 VLM 处理图像。问题：**视觉表示只编码一次**（通常经过 ViT 压缩），然后在长程交互中不断被文本摘要替代或丢弃，**细节严重丢失**。等到模型需要回看"第 3 步时物体是什么颜色"时，那个信息早已不在上下文里。

**核心矛盾**：多模态模型本身有很强的推理潜力，但它们的**"输入管道"在长程任务中不断有损压缩**，导致推理能力被严重低估。

## 三、核心方法与创新点

VISTA 的核心思想一句话：**给多模态模型一个"视觉外壳"，让它能像人眼一样——看、记、回忆、再看**。

### 3.1 三大设计支柱

**（1）视觉感知：直接看原始感官输入**

智能体接收的是**512×512 PNG 原图**（由官方 64×64 网格做 8× 最近邻放大 + 1px 网格线得到），而不是文本化的颜色编码。关键是：**模型从不被告知"世界是 64×64 网格"**——它只能从像素里自己发现结构。此外，模型可以**主动请求**放大查看任何矩形区域，实现"凑近看"。

> 这个设计的意义：强迫模型调用自己的**视觉先验**（比如对称性、连通性、运动模式），而不是依赖人为提供的符号抽象。

**（2）无损视觉记忆：原始帧永久保存**

与主流"摘要/压缩历史帧"的做法不同，VISTA **逐帧保存**环境返回的**每一帧图像**（包括中间动画帧），**原始形式、永不压缩**。这个记忆库允许模型在推理过程中**反复调取任意历史帧**，做对比、做差分、做细粒度检查。

**（3）主动检索 + 重组输入**

VISTA 提供了一组**视觉工具（visual tools）**，允许模型在推理过程中**迭代调用**：

- `inspect_frame(step)`：查看第 `step` 帧的全图
- `zoom_in(step, box)`：查看第 `step` 帧某个矩形区域的放大版
- `compare(steps)`：把多帧并列显示，做视觉对比
- ...

模型可以根据**当前推理需要**，动态决定"回头看哪一帧、看哪个区域、看多细"。这构成了一个**视觉-推理的闭环**：

```
观察 → 自然语言推理 → 发现需要更多信息 → 调用视觉工具检索/放大 → 更新推理 → 行动 → ...
```

### 3.2 系统架构：极简的 Harness

VISTA 的实现刻意保持**极简**——没有复杂的技能库、没有任务特定的工程、没有微调。它本质上是给一个**冻结的多模态大模型**（Claude Opus 5.0 或 GPT-5.6 Sol）套上一层**视觉工具接口 + 记忆管理**。

**伪代码（推理循环）**：

```python
while not done:
    obs = env.step(action)                  # 得到 512x512 PNG
    visual_memory.append(obs)               # 无损保存
    context.append(describe(obs))           # 文字描述（简要）
    
    # 模型自由推理...
    thought = llm.reason(context)
    
    # 可以随时调用视觉工具
    if thought.needs_more_visual_evidence:
        frame = visual_memory.retrieve(thought.frame_id)
        zoomed = zoom(frame, thought.region)
        context.append(visual_tool_output(zoomed))
    
    action = llm.decide(context)
```

### 3.3 三种感知表示的对比实验

作者做了一个很聪明的**信息等价、计算不等价**实验：同一个游戏状态，用三种方式表示给模型：

| 表示 | 内容 | 信息量 | Token 消耗 | 推理效果 |
|------|------|--------|-----------|----------|
| **文本网格** | 64×64 整数矩阵，每格一个颜色 ID | 理论等价 | 极高 | 可用，但效率低 |
| **2D PNG 图像**（VISTA 默认） | 512×512 彩色图像 | 理论等价 | 低 | **最好** |
| **3D 渲染场景** | 从同一游戏渲染的 3D 视角 | 理论等价 | 中 | 可用，更接近真实世界 |

三种表示**理论上信息完全等价**（可逆映射），但**实际支持的计算方式完全不同**。文本网格虽然信息完整，但需要模型在脑中"重建空间结构"；2D 图像直接呈现空间关系，最高效；3D 场景则验证了 VISTA 能推广到更真实的感知形态。

## 四、实验结果与分析

### 4.1 ARC-AGI-3 主结果

| 系统 | 模型 | RHAE 分数 | 通关率 | 动作效率（对比人类首试） |
|------|------|-----------|--------|------------------------|
| 官方 baseline（无程序） | Claude Opus 5.0 | 40.68 | — | 基准 |
| 官方 baseline（无程序） | GPT-5.6 Sol | 13.33 | — | 基准 |
| **VISTA** | **Claude Opus 5.0** | **100.00** ✅ | **25/25** | **-57.4%** |
| **VISTA** | **GPT-5.6 Sol** | **99.00** | **25/25** | 显著优于 baseline |

**关键亮点**：
- VISTA 是**第一个不依赖程序合成、纯视觉**就达到 ARC-AGI-3 满分的系统
- Claude Opus 5.0 在 VISTA 下不仅全通关，还比**人类首试玩家少用 57.4% 的动作**——说明模型的"学习效率"极高
- 同样的底层模型（GPT-5.6 Sol），换上 VISTA 外壳后从 13.33 直接跳到 99.00，**差距完全来自 harness**

### 4.2 跨基准泛化

VISTA 的极简设计让它可以直接搬到其他视觉游戏环境，**无需修改**：

| 基准 | 任务数 | VISTA (GPT-5.6 Sol) | baseline（同模型，极简 harness） | 人类参考线 |
|------|--------|---------------------|-------------------------------|-----------|
| **GameWorld** | 34 个浏览器游戏 | **显著优于 baseline** | 较低 | **超过新手人类** |
| **AI GameStore** | 10 个浏览器游戏 | **显著优于 baseline** | 较低 | **超过人类中位数** |
| **BabyVision** | 39 个视觉追踪问题 | **显著优于 baseline** | 较低 | — |

**重要观察**：GameWorld 和 AI GameStore 都是**多样化视觉游戏**，需要空间导航、策略规划、模式识别等综合能力。VISTA 在**不针对特定游戏做工程**的前提下，超过人类参考线，说明这套"视觉外壳"学到的是**通用的视觉推理策略**，而非某个游戏的特殊技巧。

### 4.3 消融实验

作者验证了三个关键设计的贡献：

| 设计 | 移除后 RHAE 变化 | 说明 |
|------|-----------------|------|
| 无损视觉记忆 | **大幅下降** | 若只保留当前帧，长程任务几乎无法完成 |
| 主动检索/放大 | **显著下降** | 若不能"凑近看"细节，复杂图案识别失败率高 |
| 自然语言推理 | **中度下降** | 若仅用视觉 embedding 推理，假设验证能力弱 |

**结论**：**无损视觉记忆是 VISTA 成功的最关键因素**——没有它，模型无法在长程任务中追踪状态变化。

## 五、与智能体认知模块的关联

### 5.1 认知架构：感知-记忆-推理的完整闭环

VISTA 的三支柱直接对应认知架构的核心模块：

| VISTA 组件 | 认知模块 | 对应研究方向 |
|-----------|---------|------------|
| 视觉感知（直接看原始 PNG） | **感知（Perception）** | 多模态感知、视觉编码 |
| 无损视觉记忆 | **记忆（Memory）** | 长程记忆、episodic memory |
| 主动检索 + 重组 | **元认知（Metacognition）** | 自我监控、信息需求判断 |
| 自然语言推理 | **推理与规划（Reasoning & Planning）** | 假设验证、因果推理 |
| 行动 + 观察循环 | **世界模型（World Model）** | 环境状态估计、转移预测 |

特别值得注意的是**"主动检索"体现了元认知能力**：模型知道自己"不知道什么"，然后**主动去查**。这正是认知科学中**"信息寻求（information seeking）"**的典型表现，也是区分"被动感知"和"主动认知"的关键。

### 5.2 对记忆研究的启示

VISTA 的"无损记忆"与当前主流"摘要式记忆"形成鲜明对比。这指向一个重要研究问题：**什么时候应该无损保留、什么时候可以有损压缩？**

结合今天入选的另一篇论文 **MemFit**（同一批次，arXiv:2610.00872），可以看到两条互补路线：
- **MemFit**：**append-only 存储** + 段落摘要索引（不覆盖原文）+ 多路检索重排——"原文永久保存，摘要只做索引"
- **VISTA**：**逐帧无损保存** + 主动视觉检索——"原始感官数据永久保存，按需取用"

两篇论文殊途同归：**不要让 LLM 在写入时做有损决策，把"读什么"的决策推迟到读取时**。这对长程智能体的记忆系统设计有很强的指导意义。

### 5.3 对世界模型研究的启示

VISTA 的"视觉外壳"本质上是一个**外置的、透明的世界状态记录器**。与内化的神经网络世界模型（如 JEPA、Dreamer）相比，VISTA 的世界模型是**显式的、可审计的**——你可以随时回查第 N 步的画面。

这与 **Kepler**（arXiv:2610.00834）的"可审计世界模型"思路形成有趣的互补：
- Kepler 把假设写成**可执行程序**（symbolic world model），用回溯检查验证
- VISTA 把假设写成**自然语言推理**，用无损视觉记忆回查验证

两条路都强调**"可验证的世界模型"**，只是验证介质不同（程序 vs. 视觉回放）。

## 六、总结与启发

### 6.1 核心亮点

1. **极简设计，巨大收益**：VISTA 没有微调、没有技能库、没有复杂工程，只是给模型配上了"能看、能记、能查"的工具，就把 RHAE 从 40.68 推到 100。
2. **无损记忆是关键**：不是更聪明的模型，而是**不丢信息的管道**成就了长程推理。
3. **主动信息寻求**：模型展现出了"知道自己不知道什么"的元认知能力——这比被动感知更接近人类认知。
4. **跨环境泛化**：同一套视觉外壳横扫多款视觉游戏基准，超过人类参考线。
5. **重新定义"能力上限"**：多模态模型的推理潜力可能被当前的输入管道**严重低估**了。

### 6.2 不足与局限

1. **上下文成本**：无损视觉记忆意味着**大量图像 token**，虽然论文未详细报告成本，但在超长程任务中可能成为瓶颈。
2. **依赖强基座模型**：VISTA 的成功建立在 Claude Opus 5.0 / GPT-5.6 Sol 这类顶级多模态模型之上，对较弱模型的效果待验证。
3. **仅限视觉模态**：VISTA 的"无损记忆"思路能否推广到音频、触觉等其他感官模态，尚待研究。
4. **官方基线对比**：官方 baseline 用的是 high reasoning effort，VISTA 用的是 xhigh，不完全对等，但 40.68 → 100 的差距远超这个因素。

### 6.3 对后续研究的启发

1. **"Harness 设计"本身就是一个独立的研究方向**：VISTA 证明了，不改模型、只改输入管道，就能带来巨大提升。这提示我们：**智能体的能力 = 模型能力 × harness 质量**，后者值得更多关注。

2. **"记忆写入"与"记忆读取"应该解耦**：MemFit 和 VISTA 都指向同一个原则——写入时无损保留，读取时智能选择。这是对当前"写入时摘要压缩"主流做法的重要修正。

3. **可审计的世界状态**：VISTA 的无损视觉记忆 + Kepler 的可执行世界模型，共同指向"**可验证、可审计的智能体推理**"这个方向。在高风险应用场景（自动驾驶、医疗决策）中，能"回放推理过程"的能力至关重要。

4. **从"视觉外壳"到"多感官外壳"**：VISTA 目前聚焦视觉，但其设计哲学（无损记忆 + 主动检索 + 重组输入）完全可以推广到多模态智能体的其他感官通道。

5. **ARC-AGI-3 的"满分饱和"问题**：VISTA 和 Kepler（今天另一篇入选论文）都达到了 100 RHAE。这意味着 ARC-AGI-3 公开集的区分度已经不足，未来需要更具挑战性的评测集——Kepler 论文也明确提出了"按首试/成本/验证感知报告"的改进方向。
