## 研究背景与动机

### 核心问题：模型之外的进化空间

现代 LLM 智能体的能力不仅取决于底层模型权重，更取决于其 **harness**——即介于模型与任务之间的提示词、工具、记忆和控制流。一个日益壮大的研究方向正在探索如何让这个 harness **自我改进**：智能体编辑自身的程序，并保留有帮助的修改。

现有工作沿两个轴展开：

| 轴 | 内容 |
|---|---|
| **编辑什么** | 提示词 → 技能文档 → 工作流 → 智能体源代码 |
| **如何搜索** | 单线性 keep-best vs. 种群/档案库 |

但几乎所有近期工作都收敛到同一种**内部优化循环**：批量 rollout → 反思 → 提出有界编辑 → 用 held-out/回归信号做门控。Yang et al. 2026 将此明确类比为梯度下降，Darwin Agent Team 2026 则将其形式化为强化学习的"操作镜像"。

### 两大失败模式

在这一共享内部循环之上，DarwinX 提出了一个互补问题：**什么是进化异构编码智能体的正确选择过程？** 两种失败模式驱动了其设计：

1. **路径依赖 (Path Dependence):** 单线性自编辑器被早期编辑所偏置并陷入平台期。Robeyns et al. 2025 已报告了这一问题。

2. **跨任务干扰 (Cross-task Interference):** 修复一类任务的编辑会悄然导致另一类任务的退化，使进化在混合任务分布上停滞。分布越广，病理越严重——许多提示词和工具修改在小范围获胜，却在完整基准上失利。

Darwin Agent Team 2026 通过**隔离**变体、保持任务族分离来应对，但这虽能遏制干扰，却将产生的专家困在了各自的谱系中。

## 核心方法与创新点

### 核心思想：将自我进化重构为种群选择

DarwinX 的标题中的"自然选择"是**字面意义**的，不是隐喻：没有金标签，没有手工挑选的赢家，只有在度量适应度下更优变体的存活，且模型本身保持不变。

> **一个冻结的模型不必是固定的智能体：harness 选择将评估计算转化为持久能力。**

与爬山法的区别在于两个关键性质：

- **编辑是加性的**，记录在不断增长的档案库中，谱系积累能力而非用一个换另一个
- **什么都不丢弃**：总体上失败的变体仍被保留，因为它可能持有的那个编辑，与另一分支的编辑组合后，能解锁两个分支单独都无法解决的任务

### 三个核心组件

```
┌─────────────────────────────────────────────────────┐
│                    DarwinX 架构                       │
├─────────────────────────────────────────────────────┤
│  1. 分支进化 (Branch Evolution)                       │
│     ├── 追踪引导的编辑 (trace-guided edits)            │
│     ├── 生存选择 (survival selection)                  │
│     └── 累积谱系增益 G(c) = G(p) + g(c)               │
│                                                       │
│  2. 种群与重组 (Population & Recombination)            │
│     ├── 档案库保留所有评分变体                           │
│     ├── 分类：改进者/中性/让步者                         │
│     └── 互补专家的合并操作                               │
│                                                       │
│  3. 模块化学习信号 (Modular Learning Signals)          │
│     ├── ∇ 失败派生信号：定位缺失能力                     │
│     ├── π* 教师派生信号：蒸馏参考解法                    │
│     └── A 自派生信号：对比成功与失败 rollout             │
└─────────────────────────────────────────────────────┘
```

### 适应度与保持-扩展契约 (Preserve-and-Extend Contract)

这是 DarwinX 最核心的设计创新。对于子节点 $c$ 和父节点 $p$，每个任务的变化量：

$$\Delta_t = \hat{p}_t(c) - \hat{p}_t(p)$$

汇总为净增益和有界回归：

$$g(c) = \sum_t \Delta_t, \quad R(c) = \sum_t (-\Delta_t)_+$$

**适应度准入规则：** 一个子节点被接受当且仅当 $g(c) > 0$ 且 $R(c) \leq \delta$。

一个推理验证智能体 $f$ 分两阶段裁决（promote → probe）：

$$\mathrm{verdict}(c) = f(g, R, \mathcal{E}, K_g) \in \{\text{promote}, \text{revert}\}$$

**直觉：** 准入者对尝试编辑是宽容的，但对信任编辑是严格的——一个变体可以在有希望但有噪声的信号下进入树，但只有通过更严格的探测后才能获得塑造未来搜索的权力。这种**双速设计**让搜索快速移动，同时不让运气累积。

### 父节点选择

下一个父节点按累积谱系增益 $G$ 排序，采样策略为：

$$p^* \sim (1-\beta)\,\delta_{\arg\max_{v \in \mathcal{S}} G(v)} + \beta\,\mathrm{Broaden}(\mathcal{P})$$

以概率 $1-\beta$ 利用确认变体的最高增益节点，否则在更广泛的种群中拓宽搜索。按累积增益排序至关重要，因为变体在不同任务子集上被筛选，原始分数不可比较。

### 重组操作：合并互补专家

当变体 $v_1, \ldots, v_n$ 解决互补任务时，DarwinX 通过合并它们的加性编辑来物化一个继承子节点：

$$H = H_0 \oplus \Delta, \quad \Delta = \Delta_{\text{code}} \oplus \Delta_{\text{skill}} \oplus \Delta_{\text{prompt}} \oplus \Delta_{\text{tool}}$$

子节点被保留当且仅当它覆盖父节点获胜的并集：$S(\text{child}) \supseteq \bigcup_i S(v_i)$。

> **关键洞察：** 保留即使总体上较弱的变体是刻意的——一个从未独自获胜的谱系，仍可能持有那个与另一分支的编辑组合后解锁任务的编辑。

### 探索与确认的分离

搜索的中心设计选择是将**探索**与**确认**分离：

- 选择器推广有界风险增益，让树保持移动
- 更严格的 avg@k 重测和保护探测决定哪些变体可以引导未来搜索并支持最终声明

## 实验设计与结果

### 评估设计：四种适应-泛化机制

单一基准分数无法判断自我进化管道学到的是可迁移的 harness 行为还是仅仅优化了评估集。因此，DarwinX 在四个基准上评估，按进化信号与测试之间的分离程度递增排列：

| 评估机制 | 基准 | 分离程度 |
|---------|------|---------|
| 域内测试时进化 | Terminal-Bench 2.1 | 最低 |
| 保留任务泛化 | TerminalWorld | 中等 |
| 合成到真实泛化 | WebArena-Infinity | 较高 |
| 跨基准迁移 | TB2.1 → SWE-bench Verified | 最高 |

### 核心结果

**Terminal-Bench 2.1 (域内进化):**
- 进化后的 harness 达到 84.7%（已验证前沿）
- 匹配基础上约 +17 个百分点的平均提升
- 匹配基础上 83.2%（+7.7），更强基础上 84.7%

**TerminalWorld (保留任务泛化):**
- 保留分割达到 68.3%，超越所有现成智能体
- +7.3 个百分点的提升

**WebArena-Infinity (合成到真实泛化):**
- 真实任务 pass@1 从 43.5% 提升到 93.0%（审计清洁）
- 仅在合成意图上进化，却泛化到真实任务

**跨基准迁移 (TB2.1 → SWE-bench Verified):**
- harness 从 Terminal-Bench 2.1 未经修改迁移到 SWE-bench Verified
- 无需域内反馈即实现迁移

### 关键发现

> **进化出的是通用智能体能力，而非基准特定的补丁，因此它能经受任务、验证器和基础模型的变化。**

消融研究将 Terminal-Bench 2.1 的增益归因于一个**进化的验证/契约技能包**——不是针对特定任务的 hack，而是通用的验证和契约管理能力。

## 与智能体认知模块的关联

### 1. 认知架构的进化视角

DarwinX 提供了一个全新的视角来看待智能体认知架构：**认知架构不必是人类设计的静态结构，而是可以通过自然选择涌现的动态组织**。

传统认知架构（如 SOAR、ACT-R）由人类专家预先定义推理、记忆、规划等模块的交互方式。DarwinX 则展示了：在模型冻结的约束下，harness（包含提示词策略、工具使用模式、控制流）可以通过种群进化自主发现有效的认知组织方式。

### 2. 与推理模块的关联

DarwinX 的三种学习信号本质上对应了推理的不同方面：

- **失败派生信号 (∇):** 类似于"知道何时停止"——通过分析失败轨迹，定位推理链中的薄弱环节
- **教师派生信号 (π*):** 类似于"学习专家的推理路径"——将参考解法蒸馏为可复用的推理策略
- **自派生信号 (A):** 类似于"元认知监控"——通过对比成功与失败的 rollout，识别使推理可靠的因素

### 3. 与记忆模块的关联

DarwinX 的**共享记忆** $K_g$ 机制值得特别关注：

$$K_{g+1} = \mathrm{Agg}(K_g, \text{worked}, \text{regressed}, \text{themes})$$

跨任务主题（如"设置成本主导超时 → 构建高效设置能力"）被注入搜索，使进化发现解决系统性瓶颈的全局能力，而非逐任务的补丁。这与智能体长期记忆中"从经验中提炼可迁移知识"的理念高度一致。

### 4. 与规划模块的关联

DarwinX 的**保持-扩展契约**本质上是一种规划约束：每次编辑必须在不破坏已有能力的前提下扩展新能力。这与分层规划中的"子目标保持"原则有深层联系——每次行动都应推进当前子目标，同时不破坏已达成的前置条件。

### 5. 对智能体自我进化的启示

DarwinX 最深远的启示或许是：**进化的通用性比进化强度更重要**。一个在窄任务上高度优化的 harness，不如一个在广泛任务上"足够好"的 harness。这与生物进化中"稳健性 (robustness)"优于"特化 (specialization)"的规律一致。

## 总结与启发

### 论文亮点

1. **概念清晰：** 将自然选择的三个核心机制（变异、选择、遗传）精确映射到智能体 harness 进化，避免了生物学隐喻的滥用
2. **保持-扩展契约：** 这一设计巧妙解决了"编辑一个能力时破坏另一个"的经典问题，通过有界回归约束 $R(c) \leq \delta$ 实现了"只进不退"
3. **重组操作：** 将互补专家的编辑合并，而非仅保留最强变体，这一设计借鉴了遗传算法中的交叉操作，但在 harness 层面实现了语义级的"基因重组"
4. **评估设计严谨：** 四种分离程度递增的评估机制，有效区分了"学到通用能力"与"过拟合评估集"
5. **实际效果惊人：** WebArena-Infinity 从 43.5% 到 93.0% 的提升，仅在合成意图上进化——这证明了 harness 进化的迁移潜力

### 局限与思考

1. **计算成本：** 种群进化需要大量 rollout 和重测，avg@k 确认机制增加了开销
2. **验证器依赖：** 进化质量依赖于基准验证器的可靠性——如果验证器有偏，进化方向也会偏
3. **合并操作的可扩展性：** 当前合并两个变体，如何处理更大规模的互补变体组合仍待探索
4. **与模型能力的交互：** 论文聚焦于冻结模型下的 harness 进化，但更强的模型是否能加速进化、或改变最优 harness 的形态？

### 对智能体研究的启发

DarwinX 提出了一个深刻的命题：**一个冻结的模型不必是固定的智能体**。这挑战了"能力来自模型"的默认假设，暗示智能体能力的很大一部分来自 harness 的组织方式。

对于智能体认知架构研究，DarwinX 的启示是：与其设计固定的认知模块交互方式，不如设计一个允许这些交互方式**自我进化**的元架构。进化的方向由任务环境的选择压力自然引导，而非由人类研究者的先验知识预设。

这或许是通往更通用、更自适应智能体的一条路径——不是设计更好的架构，而是设计更好的**进化机制**。
