## 研究背景与动机

随着LLM智能体越来越擅长处理长horizon任务，评估它们在经济系统中的表现变得越来越重要。现有的基准测试（如Vending-Bench）要么评估单个智能体与被动环境的交互，要么评估多个同质智能体（如都是自动贩卖机经营者）。

但现实经济系统是**异质的**——不同角色的企业（生产者、加工商、零售商）各司其职，通过沟通、谈判和交易来追求各自的目标。这正是博弈论研究的经典场景。

CoffeeBench要回答的核心问题是：**LLM智能体能否在一个有多角色博弈的真实经济系统中，持续做出有利可图的决策？**

---

## 核心方法与创新点

### 环境设计

CoffeeBench模拟了一个咖啡供应链，包含6个异质企业：

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ Farmer A │───→│ Roaster A│───→│Retailer A│───→ 消费者
│ Farmer B │───→│ Roaster B│───→│Retailer B│───→ 消费者
└──────────┘    └──────────┘    └──────────┘
```

- **农民（Farmer）**：生产咖啡生豆，有生产成本和延迟
- **烘焙商（Roaster）**：将生豆加工成熟豆，承担加工成本
- **零售商（Retailer）**：设定零售价格，面对消费者需求竞争

两种平行供应链：**大众咖啡**和**精品咖啡**，形成差异化竞争。

### 时间管理机制

模拟采用**事件驱动**的时间管理：

- 每天运营窗口：09:00 - 19:00
- 每个主动工具调用消耗30分钟，限制每日行动次数
- 支持异步交互：空闲状态可被消息、交易等事件重新激活

### 经济约束

为了诱导长期策略行为，环境设置了多重约束：

- 固定每日运营成本
- 库存有保质期（损耗）
- 有限存储容量
- 生产和配送有延迟
- 信用交易（Net-30付款条件），逾期有利息
- **破产机制**：现金余额为负则出局

### 核心KPI

$$\text{NetIncome} = \text{Revenue} - \text{COGS} - \text{OpEx} - \text{InterestExp} + \text{InterestRev}$$

其中 $\text{COGS}$ 采用加权平均成本基础（防止通过自我交易抬高分数的作弊行为）。

### 智能体架构

所有智能体基于ReAct框架，拥有共享工具和角色专属工具：

**共享工具：**
- `post_listing()` - 发布卖单
- `make_offer()` - 发起购买要约
- `accept_offer()` - 接受交易
- `pay_invoice()` - 支付账单
- `send_message()` - 与其他智能体自由通信

**角色专属工具：**
- 农民：`produce_item()`
- 烘焙商：`roast()`
- 零售商：`set_retail_price()`、`view_consumer_sales()`

## 实验结果与分析

### 评估方案

- 被评估模型控制 `roaster_A`
- 其余5个企业由Claude Sonnet 4.6控制
- 模拟时长90天，每个评估需要数百到数千次工具调用
- 上下文超过160k tokens时进行摘要压缩

### 主要结果

| 模型 | 净收入（$） | 工具调用次数 | 空闲天数 | 发送消息数 |
|------|------------|-------------|---------|-----------|
| GPT-5.5 | +3,109 ±1,123 | 1,269 | 0 | 140 |
| Claude Opus 4.7 | +2,782 ±2,263 | 1,117 | 0 | 88 |
| Claude Sonnet 4.6 | +2,236 ±1,489 | 1,558 | 0 | 151 |
| Gemini 3.1 Pro | +1,695 ±508 | 910 | 0 | 16 |
| GLM-5.1 | +1,597 ±1,199 | 1,373 | 0 | 78 |
| Kimi K2.6 | +454 ±1,420 | 1,173 | 4 | 14 |
| Claude Haiku 4.5 | -630 ±1,745 | 786 | 40 | 52 |
| HeuristicRoaster | -1,931 | 830 | 0 | 0 |
| PassiveRoaster | -2,765 | 0 | 90 | 0 |

### 关键发现

**1. 沟通是盈利的关键**

表现最好的模型（GPT-5.5、Claude Opus 4.7）发送了更多的消息（140条、88条），积极与其他企业沟通协调。而表现差的模型沟通明显不足。

**2. Idle-Drift失败模式**

Claude Haiku 4.5呈现了一个令人困惑的失败模式：它能产生连贯的评估和计划，但反复选择"等待"而非行动。90天中有40天处于空闲状态，最终亏损。

这说明**推理能力≠执行能力**——智能体可以"想明白"但"做不到"。

**3. 成本与性能的权衡**

GPT-5.5和Claude Opus 4.7的API成本约$80-86，而Claude Haiku 4.5仅$9.6。便宜的模型在长horizon经济博弈中表现显著更差。

## 与博弈智能体的关联

这篇论文对博弈智能体研究有几点重要启发：

### 1. 异质多智能体博弈的新范式

CoffeeBench首次提出了**异质经济角色**的基准。这比同质竞争更接近真实博弈场景——不同角色有不同的信息集、行动空间和收益函数。这正是博弈论中"不完全信息博弈"的LLM实现。

### 2. 沟通作为博弈策略

实验结果表明，主动沟通与正收益强相关。在博弈论框架下，这对应**廉价博弈（cheap talk）**——无成本的信号传递如何影响均衡结果。LLM智能体似乎天然倾向于利用沟通来协调供应链关系。

### 3. 长horizon策略的脆弱性

90天模拟暴露了智能体在长期规划中的脆弱性。Idle-drift现象说明，即使有明确的目标函数，小模型也可能在策略执行上"瘫痪"。这对博弈智能体的设计有警示：**需要显式的行动触发机制，而非仅靠推理**。

### 4. 可控的博弈环境

CoffeeBench的事件驱动设计和经济约束（破产、信用、损耗）为研究博弈智能体提供了可控的实验平台。可以在此基础上测试不同的博弈策略、谈判协议和联盟形成机制。

## 总结与启发

### 亮点

1. **首创性**：首个异质多智能体经济基准，填补了LLM评估的空白
2. **真实性**：供应链、信用交易、破产机制等设计贴近真实经济
3. **可复现性**：代码和轨迹已开源
4. **洞察力**：Idle-drift现象的发现对智能体设计有重要启示

### 不足

1. **角色固定**：被评估模型只能扮演烘焙商，无法测试不同角色的策略差异
2. **参考智能体固定**：其他5个企业用同一个模型控制，缺乏异质智能体组合的实验
3. **策略空间有限**：主要是交易和定价，缺少更复杂的博弈策略（如联盟、欺骗、信号博弈）
4. **方差较大**：3次运行的标准差较高，统计可靠性有待提升

### 启发

对于博弈智能体研究，CoffeeBench提供了一个有价值的起点。未来可以扩展到：
- 多模型混合的智能体社会
- 更复杂的博弈策略（合谋、背叛、信号传递）
- 信息不对称下的谈判博弈
- 动态联盟形成与瓦解

这篇论文最深刻的启示或许是：**在经济博弈中，"会想"不等于"会做"**。Claude Haiku 4.5的idle-drift提醒我们，博弈智能体不仅需要推理能力，更需要可靠的行动执行机制。
