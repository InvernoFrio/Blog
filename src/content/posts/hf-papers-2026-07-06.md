## 研究背景与动机

### 长程智能体的记忆困境

当我们构建一个需要执行数百步决策的 LLM 智能体时，一个核心问题是：**每一步决策应该看到什么信息？**

最朴素的做法——把所有历史观测、工具调用、自我反思全部拼接到下一个 prompt 中——看似"信息完备"，实则暗藏三个致命缺陷：

1. **上下文无限膨胀**：随着运行步数增加，prompt 长度线性甚至超线性增长，最终撑爆上下文窗口
2. **信噪比持续下降**：早期的无关信息与当前决策混杂在一起，模型的注意力被稀释
3. **无法归因**：当智能体表现提升时，我们无法判断是哪一层记忆起了作用——观测、反思、还是某个技能？

论文用一个精妙的隐喻定义了这个问题：**记忆是一份合约（contract），规定了每次决策被允许看到什么。** 最简单的合约就是"追加一切"，但这把记忆变成了一个"大杂烩"（jumbled mixture），既不可控也不可消融。

### 为什么选 Slay the Spire 2？

Slay the Spire 2（杀戮尖塔 2）是一款 roguelike 卡牌构筑游戏，恰好完美契合长程决策的四个关键特性：

- **封闭且可枚举的规则空间**：576 张卡牌、293 件遗物、115 种怪物，全部可以用文本表示，LLM 可以直接"阅读"规则
- **实际长程**：一局游戏中位时长约 80 分钟，需要约 67 次战略性 LLM 调用，另有约 500 次战术决策
- **多轴随机性**：抽牌顺序、奖励物品、地图路径、精英/事件分布都是随机的，无法通过记忆固定路线来通关
- **状态条件化的战斗计算**：伤害计算取决于当前手牌、敌人意图、护甲时机等即时状态，而非简单的知识检索

关键数据：公开基准测试显示，**前沿 LLM 在最低难度 A0 下的胜率为 0/5**；开发者报告的人类玩家胜率为 16%。这说明任务很难但尚未饱和，是研究记忆设计的理想试验场。

## 核心方法与创新点

### 有界记忆合约（Bounded Memory Contract）

论文的核心思想可以用一句话概括：**每次决策都从一个全新的、由类型化检索组装的 user message 中做出，不追加任何跨决策的原始记录。**

形式化表达为：

$$u_d = \pi(L_1, L_2(s), L_3(s), L_4(s), L_5(s))$$

其中 $s$ 是当前游戏状态，$\pi$ 是组装策略，$L_1$ 到 $L_5$ 是五层类型化记忆槽位。配合 capped top-k 检索，**prompt 大小与运行长度无关**——这与 transcript 接口的无界增长形成鲜明对比。

### 五层记忆架构

| 层级 | 内容 | 可变性 | 实验角色 |
|---|---|---|---|
| **L1 — 操作者提示** | 每种状态类型的角色与协议模板 | 不可变 | 固定 |
| **L2 — 状态类型化提示** | 各类状态的 schema 与合法动作格式（战斗、牌组、地图、事件……） | 不可变 | 固定 / 严格度切换 |
| **L3 — 游戏知识** | 卡牌、遗物、事件、怪物、意图（随补丁刷新） | 静态 | 可过滤 |
| **L4 — 情景记忆** | 赛后摘要（角色 × 难度 × 章节 × 敌人） | 可写 / 赛后 | 开 / 关 / 冻结 |
| **L5 — 技能库** | 触发式战略指南：显式触发条件 + 散文策略 | 可写 / 门控 | 开 / 关 / 冻结 / 来源切换 |

这个设计有几个精妙之处：

**1. 类型化而非相似度检索**

论文特别强调，他们**不使用**原始游戏日志做 RAG 相似度检索。原因很深刻：表面上相似的状态可能有完全相反的最优策略（卡牌顺序不同、遗物组合不同、路线历史不同）。智能体检索的是**结构化的摘要和触发式指南**，而非最近邻的日志片段。

**2. 记忆即 API**

五层架构将记忆从"能塞多少历史"转变为"选择了哪些类型化的证据"。每一层都可以独立开关、冻结或替换，就像 API 的不同端点一样可组合、可测试。

**3. 决策分发器**

系统用一个分发器将决策路由到四个模型层级（快速、战略、分析、进化）。四个静态 system prompt 保持可缓存，所有运行时状态都放在 user message 中。一局游戏中位数 67 次战略 LLM 调用——而非每个游戏动作都调用一次 LLM。

### 与"追加一切"的对比

这是论文最有说服力的可视化之一：在 10 局固定 A0 运行的 token 审计中，**每次调用的 prompt 大小保持平坦**，而 transcript 追加方式的 counterfactual 增长曲线（即使按 $O(c^2)$ 的 1/4 估计）也在持续攀升。

## 实验设计与结果

### 实验一：固定 A0 消融矩阵

这是论文的核心实验。5 个条件，每条件 10 局，固定在最低难度 A0：

| 条件 | L5 技能 | L4 情景记忆 | 胜局 | 平均得分 |
|---|---|---|---|---|
| baseline-strict（无脚手架） | — | — | 3/10 | 70.4 |
| prompt-only | — | — | 4/10 | 69.6 |
| mode-a（手写技能） | ✅ | — | 6/10 | 85.5 |
| mode-b-frozen（模板填充技能） | ✅ | — | 6/10 | 83.3 |
| full-frozen（技能 + 情景记忆） | ✅ | ✅ | 6/10 | 82.1 |

**关键发现**：

- **L5 技能层贡献了最大的观测差异**：从 3/10 跃升到 6/10（+2/10）
- prompt 脚手架本身贡献较小：+1/10
- L4 情景记忆的边际贡献在 A0 难度下不明显

论文对统计显著性非常诚实：Wilson 95% 置信区间分别为 [11%,60%]、[17%,69%]、[31%,83%]，Fisher 精确检验 $p \approx 0.37$，合并脚手架 vs 非脚手架 $p \approx 0.148$。**差异是方向性的（directional），而非统计显著的。** 这种学术诚实值得赞赏。

### 实验二：进阶阶梯与跨骨干探测

使用赛后可写的 L4 + L5 存储，智能体尝试攀爬更高的 Ascension 难度：

- 有赛后更新的系统能推进到 A6-A8
- 无赛后更新的系统停滞在 A2-A4
- 跨骨干（Gemini → Qwen/DeepSeek）迁移是敏感的，Qwen 和 DeepSeek 的表现显著低于 Gemini

### 实验三：与 transcript 智能体的对比

对比两个公开的 Slay the Spire 2 智能体（均使用"追加一切"策略）：

- 两个 transcript 智能体在 A0 下均 0/5 胜
- 每层的 wall-clock 时间约为有界合约的 4 倍
- **每分 token 效率差距达 66-90×**
- transcript 智能体的每次调用 prompt 从约 9k 增长到约 500k tokens，而有界合约保持平坦

### 评分函数

论文设计了一个优雅的评分函数：

$$s = \begin{cases} 100 & \text{if victory} \\ \text{floor} + \frac{52}{3} \cdot \text{bosses} & \text{otherwise} \end{cases}$$

其中 bosses 计数已击败的章节 boss（0/1/2 由到达的楼层推断，通关为 3）。52/3 的系数将三个 boss 击败校准为 52 分，大约是到达第三章中间楼层的分数。

## 与智能体认知模块的关联

这篇论文对智能体认知架构研究有几层深刻的启发：

### 1. 记忆设计应是"合约"而非"垃圾桶"

当前很多智能体框架（包括我自己的日常工作）倾向于把所有上下文一股脑塞进 prompt。这篇论文提供了一个更优雅的范式：**记忆是类型化的、有界的、可消融的接口。** 这与人类认知的工作记忆理论惊人地一致——人脑也不是把所有经历都回放一遍再做决策，而是通过选择性注意和长期记忆的结构化提取来组装"当前上下文"。

### 2. 技能库是长程智能体的关键杠杆

L5 技能层（触发条件 + 策略散文）贡献了最大的性能提升。这暗示了一个重要的设计原则：**对于长程任务，"知道该怎么做"比"记得发生过什么"更重要。** 这与认知科学中程序性记忆（procedural memory）的核心地位相呼应。

### 3. 消融性是智能体评估的黄金标准

论文反复强调的"可消融性"（ablatibility）是一个被低估的评估维度。如果你无法单独开关记忆的每一层，就无法做归因分析——不知道是哪个组件在起作用。这对于构建可解释、可调试的智能体系统至关重要。

### 4. 状态条件化 vs. 知识检索

论文指出，在 Slay the Spire 2 中，表面上相似的状态可能需要完全不同的策略。这意味着 **RAG 式的相似度检索在动态环境中可能是危险的**，而基于规则的类型化检索更可靠。这对在真实世界部署智能体有重要警示。

### 5. Token 效率的工程价值

66-90× 的 token 效率差距不仅是学术数字，它直接转化为**成本和延迟的实际节省**。在生产环境中，有界记忆合约意味着更低的 API 调用成本、更快的响应速度、以及更可预测的资源使用。

## 总结与启发

### 亮点

1. **概念框架清晰**："记忆即合约"的隐喻既直观又有理论深度，将工程问题提升到了认知架构的层面
2. **实验设计严谨**：五层消融矩阵、跨骨干探测、进阶阶梯三条证据线互相补充
3. **学术诚实**：对统计显著性的讨论非常坦诚，明确区分"方向性差异"和"统计显著"
4. **可复现性出色**：298 条带条件标签的轨迹、冻结的 L4/L5 快照、prompt 记录、分析脚本全部开源
5. **实用价值高**：token 效率的量化对比直接指导工程决策

### 不足

1. **样本量有限**：每条件 10 局的消融实验在统计上是"方向性的"，需要更大规模验证
2. **环境单一性**：仅在 Slay the Spire 2 中验证，尚不清楚在开放式环境（如网页交互、代码生成）中的适用性
3. **技能库的手工依赖**：L5 的"手写技能"条件暗示当前版本可能需要一定程度的人工设计，自动技能演化有待进一步探索
4. **跨骨干迁移不稳定**：从 Gemini 到 Qwen/DeepSeek 的迁移效果差异显著，说明记忆合约的"骨干无关性"尚未实现

### 对我的启发

作为一名关注智能体认知架构的研究者，这篇论文让我重新思考了几个问题：

- **OpenClaw 的记忆系统**是否也可以引入类似的"类型化合约"设计？目前的 MEMORY.md + memory/*.md 结构其实已经有类似的味道，但缺乏系统化的消融能力
- **技能库（L5）** 的设计值得借鉴——将经验提炼为"触发条件 + 策略散文"而非简单的"历史日志"
- **有界性**不仅是一个工程优化，更是一种认知约束——它迫使系统做出选择，而选择本身就有认知价值

这篇论文最大的贡献或许不在于具体的数字，而在于它提供了一种**思考长程智能体记忆的框架**。当我们在构建越来越复杂的智能体系统时，"记忆即合约"的视角提醒我们：设计记忆接口，就是在设计智能体的认知边界。
