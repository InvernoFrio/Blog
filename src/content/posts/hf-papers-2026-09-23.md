## 研究背景与动机

### 智能体 = 模型 + Harness

现代 LLM 智能体并非单纯的模型，而是一个**系统**：冻结的骨干模型被包裹在一层"Harness"中——包括提示词、控制流、工具接口、记忆与上下文管理。大量实际产品进展来自 Harness 工程，而非新模型权重。

### 递归自改进（RSI）的兴起与隐忧

近期方法开始用 LLM 自动化 Harness 优化：在演化集上运行智能体、收集反馈、生成候选修改、评估选择——形成**递归自改进（RSI）**循环。然而，这种递归进化面临一个关键问题：**过拟合**。

研究发现，演化集上的性能提升可能来自：
- **基准特定拟合**：编码了任务名称、实体等特定模式
- **噪声追逐**：被评估随机性误导的候选被选中
- **复杂度累积**：增加机制但不提升核心能力

这些因素导致演化集上的增益在分布外（OOD）基准上大幅缩水甚至消失。

### 核心问题

> 能否在保持 Harness 完全可编辑的同时，让递归自改进学到**可迁移的通用机制**而非基准特定的技巧？

## 核心方法与创新点

RRSI 的核心思想是将机器学习中的**正则化原理**翻译到 Harness 演化空间：不限制能改什么，而是约束**怎么改**和**选什么**。

### 形式化框架

智能体 $A = (\pi, H)$，其中 $\pi$ 为冻结骨干策略，$H$ 为 Harness。对任务集 $\mathcal{D}$：

$$S(H; \mathcal{D}) = \mathbb{E}_{x \sim \mathcal{D}} \mathbb{E}_{\tau \sim A(\cdot|x)} [r(x, \tau)]$$

$$C(H; \mathcal{D}) = \mathbb{E}_{x \sim \mathcal{D}} \mathbb{E}_{\tau \sim A(\cdot|x)} [c(\tau)]$$

其中 $r$ 为验证器得分，$c$ 为策略 token 消耗。演化循环：

$$H_{t+1} = \arg\max_{H' \in \mathcal{H}_t \cup \{H_t\}} \hat{S}(H'; \mathcal{D}_{\text{evolve}})$$

### 提案端正则化（控制搜索容量的使用方式）

**1. $L_0$ 风格的退火更新稀疏性**

限制每轮候选中可包含的独立可归因编辑数：

$$b_t = \lceil b_{\min} + (b_{\max} - b_{\min}) \cdot \tfrac{1}{2}(1 + \cos(\pi t / T)) \rceil$$

- 早期轮次允许较多编辑以发现新机制
- 后期轮次逐渐稀疏，使每个编辑可被精确归因
- 类似 $L_0$ 范数对活跃编辑数的基数约束

**2. 证据感知的信用分配**

记录每个候选的：修改组件、测试假设、源 diff、得分与成本变化、是否被接受。后续轮次基于此历史决策——被拒绝的机制保留为负证据，成功的机制保留明确信用。避免反复测试已证伪的假设。

**3. 结构化探索**

当搜索停滞（前 $w$ 轮进展在噪声带 $\delta$ 内）时，预留部分提案预算给尚未尝试的组件。类似多样性/熵正则化，将搜索容量重新导向未充分探索的机制。

### 选择端正则化（控制哪些改进可以成为永久状态）

**1. 泄漏筛查（Critic）**

在完整评估前，Critic 审读候选 diff，拒绝包含任务名、实体名、特定值等基准特定内容的编辑。关键是：泄漏的候选从不会获得虚高的演化集分数。

**2. 稳定性感知接受**

预先评估基础 Harness 估计噪声带 $\delta$。候选必须满足：

$$\hat{S}(H') \geq S^* - \delta$$

防止搜索通过一系列微小回归"走下坡"。

**3. $L_2$ 风格的复杂度感知接受**

类似 Ridge 回归的收缩效应：抑制资源消耗的无节制增长，不要求消除特定组件，但拒绝成本增长不成比例的候选。

### 正则化类比总结

| RRSI 机制 | 经典正则化类比 | 作用 |
|---|---|---|
| 退火编辑预算 | $L_0$ 稀疏约束 | 限制单轮更新的活跃编辑数 |
| 结构化剪枝 | $L_1$/Lasso 稀疏化 | 移除持续无效的组件 |
| 复杂度感知接受 | $L_2$/Ridge 收缩 | 抑制资源消耗的无节制增长 |

## 实验结果与分析

### 实验设置

- **8 个基准**，跨 3 个领域：编程、智能体工作空间、工程设计
- 每个领域在单一演化套件上演化，然后在**保持基准**上评估
- 评估维度：演化集得分、OOD 迁移得分、策略 token 消耗

### 核心结果

| 指标 | 表现 |
|---|---|
| 演化集提升 | 最高 **+14.1 分** |
| OOD 基准提升 | 最高 **+4.7 分**（6 个保持基准全部提升） |
| 效率提升 | 策略 token 消耗减少 **30%** |
| OOD 超越基线 | 比先前基线平均高出 **22.9%** |

### 关键发现

- **无正则化的演化严重过拟合**：演化集增益在 OOD 上大幅缩水，多个方法甚至低于初始 Harness（$H_0$）
- **RRSI 的增益可迁移**：在与演化环境显著不同的任务和评估设置上保持改进
- **效率与效果兼得**：学到更简洁的 Harness 同时提升性能

## 与智能体认知模块的关联

### 对智能体架构设计的启发

1. **Harness 即认知架构**：论文将提示词、控制流、工具接口、记忆管理统一为"Harness"，这正是智能体认知架构的操作化定义。RRSI 提供了一种自动优化认知架构的系统化方法。

2. **泛化 vs 过拟合的认知启示**：智能体认知模块（推理、规划、记忆）的设计同样面临"在特定任务上有效但不通用"的问题。RRSI 的正则化思想可以迁移到认知模块的自动设计中——约束搜索空间的使用方式而非限制设计空间本身。

3. **稀疏更新与可解释性**：退火编辑预算使每个修改可被精确归因，这为理解"哪个认知模块的修改贡献了性能提升"提供了方法论。

4. **证据感知的信用分配**：记录演化历史并避免重复测试已证伪假设，这与元认知中的"知道自己不知道什么"高度相关。

### 对递归自改进研究的启示

- RSI 不应只追求演化集得分，**迁移能力**才是核心指标
- 正则化是 RSI 中被忽视但关键的组件
- 效率（token 消耗）应作为 RSI 的一等优化目标

## 总结与启发

### 亮点

- **问题定义清晰**：首次系统性地将 Harness 演化的过拟合问题形式化
- **方法优雅**：将经典正则化思想（$L_0/L_1/L_2$）创造性地迁移到 Harness 搜索空间
- **实验扎实**：8 个基准、3 个领域、严格的 OOD 评估协议
- **实用价值高**：代码开源，30% 的 token 节省意味着显著的成本降低

### 不足

- 论文截断部分未见完整的实验消融，各正则化组件的独立贡献有待确认
- 演化仍需在每个领域单独进行，跨领域的 Harness 迁移未探索
- 噪声带 $\delta$ 的估计依赖预评估，对非平稳环境的适应性存疑

### 一句话总结

> RRSI 证明了"怎么改"比"改什么"更重要——通过正则化搜索轨迹而非限制编辑空间，让智能体 Harness 的递归自改进学会可迁移的通用机制。
