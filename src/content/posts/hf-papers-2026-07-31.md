# CAST: Game Solvers as Turn-Level Teachers for LLM Agents

## 📋 论文基本信息

## 🔍 研究背景与动机

### 问题：稀疏奖励下的信用分配困境

用强化学习训练LLM玩长周期游戏（如推箱子、扫雷）时，一个核心瓶颈是**信用分配（Credit Assignment）**问题：

- **RLVR**（Reinforcement Learning with Verifiable Rewards）在单轮任务中表现优秀，但在多回合游戏中，最终的 0/1 奖励过于稀疏——一局游戏可能有几十步，但只知道"赢了"或"输了"，完全无法区分哪些决策是关键的。
- 这就像考试只告诉你总分，却不告诉你哪道题做对了、哪道题做错了——你根本不知道该改进什么。

### 现有方法的局限

| 方法 | 问题 |
|------|------|
| **搜索（MCTS等）** | 计算成本高，难以规模化 |
| **过程奖励模型（PRM）** | 需要额外训练，且标注成本高 |
| **跨轨迹比较（GiGPO）** | 信号可靠性不足，只能做轨迹级对比 |
| **SFT on solver trajectories** | 只覆盖专家访问的状态，LLM偏离后无指导 |

### 关键观察

> 游戏求解器（Solver）可以完成从任意中间状态出发的游戏。这意味着它天然拥有一个**状态价值函数**——距离胜利还有多远。

这个观察是整个方法的出发点：既然求解器知道每个状态有多"好"，我们就能用它来评估LLM的每一步动作是否让状态变好了。

## 🧠 核心方法与创新点

### 1. 游戏建模为多回合MDP

将每个游戏形式化为有限视野MDP $\mathcal{M}=(\mathcal{S},\mathcal{A},P,r,H)$。在每个回合 $t$：

- LLM策略 $\pi_\theta$ 观察状态 $s_t$ 的文本表示
- 采样动作 $a_t \sim \pi_\theta(\cdot \mid s_t)$
- 环境转移到 $s_{t+1}$
- 奖励是稀疏的：$r_t = 0$（$t < T$），$R(\tau) = \mathbf{1}\{s_T \in \mathcal{S}_{\text{solved}}\}$

### 2. 求解器优势：逐回合的信用信号

CAST的核心创新是定义了**求解器优势（Solver Advantage）**。

**Cost-to-go（代价函数）**：对于状态 $s$，$N(s)$ 是从该状态到达胜利所需的最少步数。

- 推箱子/华容道：最少移动次数
- 扫雷：最少揭示次数

**求解器状态价值**：

$$V^{\pi_{\text{Solver}}}(s) = -N(s)$$

越接近目标的状态，价值越高。

**求解器优势**：

$$A^{\pi_{\text{Solver}}}(s_t, a_t) = -1 + N(s_t) - \mathbb{E}_{s_{t+1}}[N(s_{t+1})]$$

这个公式的意义很直观：**如果一个动作让代价函数下降（离胜利更近），它的优势就是正的；反之就是负的。**

### 3. 理论核心：无logit蒸馏等价性

这是论文最漂亮的理论贡献：

**定理（Theorem 2.1）**：在soft-optimal求解器假设下，最大化求解器优势等价于**在策略蒸馏（On-Policy Distillation）**，将LLM的动作分布与求解器对齐。

直觉解释：
- 传统蒸馏需要教师模型的完整logit分布（对整个词表的概率分布），而求解器只返回标量值
- CAST证明：**标量优势本身就隐含了教师的动作偏好**——不需要完整的logit分布，一个标量就够了
- 这实现了高效的"无logit蒸馏"

### 4. 信号稳定化

求解器信号的绝对尺度在不同游戏中差异很大，可能包含极端值。CAST用两个轻量级步骤解决：

1. **asinh变换**：平滑压缩极端值，同时保留小信号的分辨率。理论上等价于一个鲁棒化的KL约束。

2. **批次级RMS归一化**：消除跨领域的尺度差异

$$\hat{A}_t^{\text{solver}} = \frac{\text{asinh}(\alpha \cdot A_t^{\text{solver}})}{\sqrt{\frac{1}{T}\sum_{t=1}^{T}\text{asinh}(\alpha \cdot A_t^{\text{solver}})^2 + \epsilon}}$$

### 5. 完整训练流程

将求解器优势注入GRPO框架：

$$\hat{A}_i = \hat{A}_i^{\text{outcome}} + \lambda \cdot \hat{A}_i^{\text{solver}}$$

其中 $\hat{A}_i^{\text{outcome}}$ 是GRPO原有的轨迹级优势，$\hat{A}_i^{\text{solver}}$ 是求解器提供的回合级优势。两者互补：

- 轨迹级信号告诉LLM"这局是赢是输"
- 回合级信号告诉LLM"这一步走得好不好"

## 📊 实验结果与分析

### 实验设置

- **训练游戏**：Sokoban（推箱子）、Minesweeper（扫雷）、Rush Hour（华容道）
  - 覆盖不同挑战：长期规划、部分可观测推理、约束组合搜索
- **评估游戏**：除上述三个，还零迁移到 ALFWorld（具身家务）和 WebShop（网页购物）
- **基线**：GRPO（纯结果奖励）、DAPO、GiGPO（跨轨迹比较）、SFT

### 核心结果

| 游戏 | 评估设置 | CAST表现 |
|------|----------|----------|
| Sokoban | 域内 + 未见难度 | 所有游戏中最优 |
| Minesweeper | 域内 + 未见难度 | 所有游戏中最优 |
| Rush Hour | 域内 + 未见难度 | 所有游戏中最优 |

**关键发现**：

1. **全面超越基线**：CAST在每个游戏、每个评估设置下都优于所有训练方法
2. **训练效率更高**：CAST达到DAPO峰值验证性能所需的训练步数显著更少
3. **强大的零样本迁移**：
   - 在Sokoban上训练 → 零迁移到ALFWorld和WebShop，取得最高平均性能
   - 说明求解器提供的信用信号是**通用的**，不局限于特定游戏
4. **消融实验**：验证了求解器优势权重和信号变换的必要性
5. **求解器开销可忽略**：精确求解器带来的额外计算成本极小
6. **学习价值网络的可行性**：当没有精确求解器时，用学习到的价值网络替代，仍能保留大部分收益

## 🔗 与智能体认知模块的关联

### 1. 信用分配是智能体规划的核心问题

CAST解决的信用分配问题，本质上是智能体**规划能力**的核心挑战：

- 在长周期任务中，智能体需要知道哪些决策是关键的
- 人类做规划时也会进行"反事实推理"：如果当时没走这步，结果会怎样？
- CAST的求解器优势本质上是一种自动化的反事实分析

### 2. 过程信号 vs 结果信号

这对智能体训练有深刻启示：

- **结果信号**（赢/输）只能告诉智能体"做得对不对"
- **过程信号**（求解器优势）能告诉智能体"每一步做得好不好"
- 这与人类学习的"过程性反馈"类似——教练不只看你比赛赢没赢，还会指出每个技术动作的问题

### 3. 知识蒸馏的新范式

"无logit蒸馏"对智能体知识迁移有重要启发：

- 传统蒸馏需要教师模型的完整输出分布
- CAST证明只需要**标量评估信号**就够了
- 这意味着我们可以用任何能评估状态好坏的"专家"（不一定是神经网络）来指导LLM学习
- 例如：用规则引擎、启发式算法、甚至人类专家的直觉判断作为"求解器"

### 4. 从游戏到真实任务

CAST的零样本迁移到ALFWorld和WebShop表明：

- 在结构化游戏中学到的信用分配能力，可以泛化到更复杂的具身/网页任务
- 这暗示了一种**课程学习**策略：先在简单游戏中训练信用分配能力，再迁移到真实场景

## 💬 个人点评

### 亮点

1. **理论优美**：将求解器优势等价于在策略蒸馏的证明，是这篇论文最大的亮点。它把一个工程直觉（"求解器知道每个状态好不好"）上升为严格的理论结果。

2. **实用性强**：精确求解器的开销可忽略，学习价值网络作为替代方案也很有效。这使得方法易于部署。

3. **零样本迁移**：在Sokoban上训练就能迁移到ALFWorld和WebShop，说明学到的是通用的信用分配能力，而非特定游戏的策略。

4. **信号设计精巧**：asinh变换 + RMS归一化的组合，既解决了数值稳定性问题，又保留了理论性质。

### 不足

1. **依赖求解器**：方法的前提是有可用的游戏求解器。对于没有明确求解器的开放世界任务，需要额外训练价值网络，这增加了一层不确定性。

2. **评估环境局限**：三个游戏都是完全规则化的、有明确胜负的。真实世界的任务往往没有如此清晰的"成功"定义。

3. **理论假设**：soft-optimal求解器假设在实际中可能不完全成立。如果求解器本身不够强，提供的信用信号质量会下降。

4. **与LLM推理的结合**：论文没有探索CAST与chain-of-thought推理的结合。在更复杂的任务中，LLM可能需要显式的推理步骤，而不仅仅是动作选择。

### 总评

CAST是一篇**理论扎实、实验充分、实用性强**的工作。它为LLM智能体训练中的信用分配问题提供了一个优雅的解决方案，"求解器即教师"的范式可能启发更多后续工作。对于关注智能体训练和推理的研究者来说，这是一篇值得细读的论文。
