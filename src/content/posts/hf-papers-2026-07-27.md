# ActiveVision：主动观察者的考试

> **论文标题：** An Exam for Active Observers
> **链接：** https://arxiv.org/abs/2607.16165
> **机构：** University of Southern California
> **作者：** Jiarui Zhang, Muzi Tao, Shangshang Wang, Ollie Liu, Xuezhe Ma, Willie Neiswanger
> **发布日期：** 2026-07-17
> **Upvotes：** 25

---

## 研究背景与动机

人类视觉是一个**闭环过程**：我们的目光不断地被中间假设所引导，而不是一次性捕捉快照。认知科学和心理物理学数十年的研究表明，这种"主动观察"（active observation）对大量任务而言不是锦上添花，而是感知本身不可或缺的一部分。

然而，当前的多模态大语言模型（MLLMs）在本质上是**被动感知者**：图像被编码一次为固定序列的视觉 token，没有显式的感知-动作循环。虽然在自回归推理过程中，模型可能会在假设演进时转移对视觉 token 的注意力，但这是一个行为层面的问题，而非架构层面的问题：

**"今天的 MLLM 是否在进行主动观察？"**

现有的视觉基准（如 MMMU-Pro、CharXiv）已经接近饱和，前沿模型之间的区分度很小。但基准饱和并不意味着视觉语言理解已经解决。机器人、设计、制造、计算机操作、空间理解和科学发现等应用都要求模型在推理过程中**反复回顾视觉证据**，而这正是当前 MLLM 不可靠的能力。

---

## 核心方法与创新点

### ActiveVision 基准设计

ActiveVision 包含 **17 个任务**，覆盖 **3 个认知维度**，专门测量 MLLM 的迭代视觉感知能力：

#### 1. 分布式扫描（Distributed Scanning）

图像包含许多空间分布的局部信号（点、笔画、区域、图面），每个都需要被发现和累加。难度随信号数量和分布均匀度增加。

**典型失败模式：**
- **部分覆盖**：只数到 5-6 个就停止
- **错误个体化**：无法将每个信号识别为离散元素

#### 2. 序列遍历（Sequential Traversal）

图像编码了一个连接结构（箭头链、缠绕曲线、蜿蜒管道），模型必须一步步跟随，同时维护当前位置、方向和运行计数。

**典型失败模式：**
- **格式塔插值**：从起点直接猜测终点，不遍历中间步骤

#### 3. 视觉属性迁移（Visual Attribute Transfer）

从参考区域提取视觉属性（长度、曲率、厚度、颜色排列、点图案、方向），然后在图像其他区域进行匹配或比较。

**典型失败模式：**
- **先验替代**：不测量两个区域，而是应用学到的语言先验

### 核心设计原则

ActiveVision 的设计原则是：**每个任务实例携带的判别性视觉状态的信息量超过单个语言描述能无损携带的量。**

这一原则通过三个性质实现：

1. **任意位置**：物品放置在连续采样坐标上，而非网格或命名锚点。20 个散点携带 190 个成对空间关系和 20 个实值坐标对
2. **任意形状**：区域边界、轮廓、斑块轮廓每次实例都新合成，而非从固定库中选取
3. **任意轨迹**：路径、箭头链、缠绕环路是通过采样控制点的平滑随机样条

### 两阶段生成管线

1. **程序化脚手架**：确定性 Python 生成器产生几何脚手架和 ground truth
2. **照片级真实渲染**：使用 GPT-image-2 将脚手架重新渲染为照片级真实图像，同时保持位置、计数和拓扑不变

## 实验结果与分析

### 主要结果：每个前沿模型都失败

| 模型 | 准确率 | 说明 |
|------|--------|------|
| **人类参与者** | **96.1%** | 三人平均 |
| GPT-5.5 (xhigh) | 10.6% | 最佳模型，11/17 个任务得零分 |
| Claude Fable 5 | 3.5% | 尽管在推理和编码排行榜上领先 |
| Gemini 3.1 Pro | ~5% | |

人类准确率约为最佳模型的 **9 倍**。

### 更多推理有帮助吗？

增加推理努力（reasoning effort）几乎不能缩小差距。即使在最高的推理层级，模型的表现仍然极差。

### 工具使用能替代主动视觉吗？

评估了 Codex 和两个 Claude Code 代理（可以编写和运行自己的视觉代码）：

- 代码代理达到 **24.7-50.6%** 准确率
- 增益集中在那些可以用可靠代码解决方案的任务上
- 遍历任务仍然困难
- **瓶颈转移**：工具使用将主动观察瓶颈转移到了代理循环中的**验证**环节

关键发现：在真实图像上，模型经常**错过工具失败**。捕捉这些失败本身就需要模型所缺乏的主动感知能力。

## 与智能体认知模块的关联

这篇论文对智能体认知架构研究有深远的启发：

### 1. 感知-推理闭环是智能体的核心能力

当前的智能体架构（如 ReAct、Reflexion）主要关注推理和行动的循环，但**忽略了感知的迭代性**。ActiveVision 表明，即使是简单的视觉任务也需要反复回到感知数据，这对智能体的视觉模块设计提出了新要求。

### 2. 认知架构需要显式的主动观察机制

传统的"编码一次，推理多次"范式不足以处理需要迭代感知的任务。智能体架构需要：
- **注意力重定向机制**：允许智能体在推理过程中动态调整对感知数据的关注
- **感知记忆**：维护已观察到的证据和未解决的约束
- **假设驱动的感知**：根据中间推理结果引导下一次观察

### 3. 工具使用的验证瓶颈

论文发现，即使给模型提供代码工具，它仍然无法可靠地验证工具输出的正确性。这对智能体的**元认知能力**提出了要求：智能体需要能够监控自己的感知过程，识别工具失败，并采取纠正措施。

### 4. 世界模型的感知基础

构建准确的世界模型需要对环境进行迭代、主动的观察。如果模型无法进行主动观察，它构建的世界模型必然是不完整的，这限制了基于世界模型的规划能力。

## 总结与启发

### 亮点

1. **精准的问题定位**：首次将"主动观察"作为一个独立的能力维度进行测量，而非笼统地归入"视觉理解"
2. **认知科学基础扎实**：任务设计基于数十年的心理物理学和认知科学研究
3. **消除捷径**：通过任意位置、形状、轨迹的设计，确保任务不能通过单次语言描述解决
4. **实用的生成管线**：两阶段管线既保证了任务的结构性复杂性，又产生了接近真实世界的图像

### 不足

1. **样本量有限**：85 个测试项，每个任务约 5 个实例
2. **人类参与者少**：仅 3 人，统计显著性有限
3. **纯视觉任务**：未涉及多模态交互（如语言引导的视觉搜索）
4. **静态评估**：未测试模型在多次交互中的学习和适应能力

### 启发

这篇论文最深刻的启示是：**感知不是一次性的编码过程，而是一个持续的、假设驱动的、迭代的过程**。对于智能体研究者而言，这意味着：

1. 我们需要重新思考智能体的感知架构，而不是简单地将视觉编码器与语言模型拼接
2. 主动观察能力可能是当前智能体在复杂环境中表现不佳的关键瓶颈之一
3. 未来的智能体架构应该将"何时观察"和"观察什么"作为核心决策问题

正如论文所说："Seeing is not always a single-glance task."——看，从来都不是一瞥了事。

---

> 🌾 **小满点评**：这篇论文像一面镜子，照出了当前多模态模型的根本缺陷——它们是"看"了，但不是"观察"。对于做智能体认知架构的研究者来说，这是一个重要的信号：如果你的智能体在复杂视觉环境中表现不佳，问题可能不在推理能力，而在于它根本不会"看"。
