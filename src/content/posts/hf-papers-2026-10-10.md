## 研究背景与动机

让智能体进入一个**完全陌生的交互环境**——不知道物体是什么、动作有什么效果、甚至不知道"赢"的判定条件——是检验 agent 智能的硬核场景。ARC-AGI-3 正是这种设定：64×64 网格游戏，动作语义未知，规则完全靠自己试出来。

现有的 code world model 路线（WorldCoder、GIF-MCTS 等）已经展示了"从交互中学习可执行程序作为世界模型"的可行性。但这篇论文点出了一个关键的、常被忽视的问题——**版本空间歧义（version space ambiguity）**：

> 有限的交互历史，通常可以支持多个彼此不同的世界模型。它们都能复现已观察到的转移，但在未观察到的状态上给出**不同的预测**。

论文举了个漂亮的例子：如果观察到的所有墙都在第 7 列，那么"箱子遇到墙会停"和"箱子走到第 7 列会停"两个假设，能解释同样的轨迹，但当墙出现在别处时预测完全不同。回放（replay）可以否决不一致的程序，却无法在一致的候选里选出正确的那个。

因此智能体需要的不只是"一个能跑通历史的世界模型"，而是**能随证据到来而显式维护和修订的泛化假设**。这正是 Memento 系列一贯的思路——把外部记忆而非模型参数当作学习状态：

- **Memento**：情景记忆，把交互结果写入记忆、检索来改善决策（学策略侧）
- **Memento 2**：把记忆写入形式化为策略评估、读取形式化为策略改进（有状态反思学习）
- **Memento-Skills**：把学习状态扩展到可复用的程序性记忆（技能）

前三作主要改善**策略侧**（该做什么决策/程序），而陌生环境引入了互补的**模型侧**问题（世界如何运作）。Memento 3 就是这个拼图的最后一块：**Code as Model**——用自然语言规则书 + 可执行代码显式学习世界模型，且底层 LLM 全程冻结。

## 核心方法与创新点

### 1. Code as Model：双表示的世界模型假设

智能体的"学习状态"是一个三元组：

$$Z_t = (H_t, \psi_t, \theta_t)$$

其中 $H_t$ 是交互记录（证据），$\psi_t$ 是**自然语言规则书**（语义记忆，记录关于物体、动作语义、动力学、目标的当前假设），$\theta_t$ 是规则书编译出的**可执行程序**（转移预测器 + 推断的目标条件）。两者合起来 $h_t = (\psi_t, \theta_t)$ 构成持久的世界模型假设。

两个表示分工明确：**规则书陈述"我相信环境规则是什么"，代码固定"这些规则如何被应用"**。规则级的理解变化必须先写进规则书再编译进代码；而纯粹的实现 bug 可以只改 $\theta_t$ 不动 $\psi_t$。这个区分非常干净——它把"认知更新"和"工程修复"解耦了。

规则书可以对未观察到的机制**留白**（underspecified），从而允许多个可执行实现 $\llbracket \psi \rrbracket \subseteq \Theta$ 并存。这直接回应了版本空间问题：不强行过早收敛到单一假设。

### 2. 五阶段反思闭环

每个交互步推进学习状态的五个阶段（本质是更新算子 $U$）：

1. **观察**：执行 $a_t$ 得到 $o_{t+1}$，追加进记录 $H_{t+1}$
2. **反思**：冻结 LLM 从 $\{$retain, revise_rulebook, repair_code$\}$ 中选一个修订决策 $d_{t+1}$——预测不匹配可能源于环境规则错了，也可能只是代码没实现对
3. **规则修订**：若选择修订，LLM 的修订算子 $\Delta_\phi$ 生成新规则书 $\tilde\psi_{t+1}$
4. **编译**：规则书引导的编译器 $\mathcal{C}_\phi$ 把规则书编译成可执行实现 $\tilde\theta_{t+1}$
5. **验证**：双重门槛接受——(a) LLM 判断代码对规则书**忠实**（$\theta \in \llbracket\psi\rrbracket$，语义条件）；(b) **cell-exact 回放**：程序回放全部历史动作序列，预测的每一帧 64×64 网格必须与记录逐格一致

$$\mathrm{verify}(\theta; H_t) = \prod_{i<t} \mathbf{1}[\hat{o}_\theta(H_i, a_i) = o_{i+1}]$$

只有通过这两关的假设对才被采纳用于规划。值得注意的是，接受标准**不依赖 LLM 的置信度排序**（那会排除正确候选），而是"LLM 语义忠实性判断 + 精确执行检查"的组合。

### 3. 模型化的递归自改进（RSI）

论文给出的形式化定义：智能体自主修订持久世界模型假设 $h_t$ 以改善后续预测与决策；$h_t$ 同时是**被修订的对象**和**进一步学习的工具**——它引导规划与探索，从而塑造下一轮修订所依据的证据。这就是递归回路。

底层 LLM 参数全程不变（$\phi_{t+1} = \phi_t = \phi$），所有的"改进"都发生在外部件：规则书、代码、交互记录。用 Bayes-adaptive POMDP 的语言，理想信念更新是

$$b_{t+1}(s', m) = \frac{\ell_m(y_{t+1} \mid s') \sum_s \mathbf{1}[s' = T_m(s, a_t)]\, b_t(s, m)}{p(y_{t+1} \mid b_t, a_t)}$$

Code as Model 用"构造并通过验证的规则书-可执行对 + 重建的内部状态"来近似这个信念（点质量近似 $\hat{b}_t$）。规划器在该假设下做模型条件化的最短路搜索，目标是预算内到达目标、并最小化条件动作成本。

另外细节很赞：**Git 记忆**。规则书和代码存放在一个 Git 仓库，每轮迭代 commit 并打 tag。智能体自己可以 diff 任意两个版本、回滚被改坏的可执行程序、召回已测试过的假设——仓库记录的是**学习轨迹**而非快照。

### 4. 群体扩展：N 个世界模型并行

既然有限证据下版本空间天然多解，就不要把整局押在一个早期随机抽样的假设上。群体扩展维护 $N$ 个规则书-可执行对（共享同一交互记录），每个规划 episode 采样一个行为等价类的代表来引导探索，产生的转移用来检验所有成员，冲突的成员被修复。$N=1$ 退化为单模型设定。这本质是 posterior sampling 思想的实现，但论文诚实地说：群体是剩余版本空间的计算近似，**不是校准的贝叶斯后验**。

## 实验结果与分析

### ARC-AGI-3：25 个公开游戏全通关

实验设定：以 baseline1 代码库为起点，在 Claude Code 中以 **Claude Opus 5** 为骨干（推理强度 high）。所有基线数字取自 ARC Prize 官方 scorecard。RHAE 是人类相对动作效率（封顶 100，需要全部关卡通关且动作数低于人类才能达到）。

**总体结果对比**（Table 1/2 汇总）：

| 系统 | 平均 RHAE | 通关游戏数 | 通关关卡数 | 总动作数 | 动作数/人类 |
|------|-----------|-----------|-----------|---------|-----------|
| Continual Harness | 20.5 | 3 | 64 | 14,558† | — |
| DreamTeam | 38.1 | 6 | 98 | 9,789† | — |
| OPINE-World | 78.4 | 20 | 160 | 12,859† | — |
| NOOA | 85.1 | 19 | 170 | 11,697† | — |
| baseline1 | 99.0 | 25 | 183 | 8,347 | 0.49 |
| **Memento 3 (Ours)** | **100.0** | **25** | **183** | **7,518** | **0.44** |
| 人类基线 | — | — | — | 17,135 | 1.00 |

† 标记的系统留有未通关游戏，其总动作数是"跑完花费"而非"解题成本"，不可直接比较。

- Memento 3 在**全部 25 个游戏**上达到 RHAE 100（含 sc25、tn36 等 baseline1 未满分的游戏），平均 RHAE 100.0，比 Claude Opus 5 + ARC Prize 官方 harness 高 **59.3 分**
- 总动作数 7,518，是人类基线 17,135 的 **44%**；逐游戏比值最低 0.20（m0r0），最高 0.67（lf52），中位数 0.42
- 唯一同样全通关的 baseline1 用了 8,347 个动作（人类的 49%），Memento 3 还省了 10%

### 消融：规则书到底有没有用？

移除规则书、只留 code world model，其余（harness、回放验证器、规划执行器、骨干、推理强度）逐字节一致。按人类每关动作数选易/中/难三档各一个游戏：

| 游戏 | 难度档 | 人类动作/关 | 动作数(有规则书) | 动作数(无规则书) | agent轮数(有) | agent轮数(无) |
|------|--------|-----------|----------------|----------------|--------------|--------------|
| ft09 | 易 | 35 | 75 | 79 | 132 | 174 |
| ka59 | 中 | 104 | 341 | 382 | 298 | 310 |
| cn04 | 难 | 132 | 201 | 216 | 248 | 346 |
| **合计** | | | **617** | **677** | **678** | **830** |

完成度相同的前提下，规则书变体动作数少 **9%**、agent 轮数少 **18%**——持久语义记忆让智能体更快收敛到有效的可执行模型。

### 群体扩展：wa30 上 N=2

在人类动作基线最大的 wa30（9 关）上跑 N=2，骨干与 harness 固定不变：

| | 人类基线 | N=1 | N=2 群体 | N=2 vs N=1 |
|---|---------|-----|---------|-----------|
| 总动作数 | 1,843 | 899 | 597 | **0.66×** |
| RHAE | 100 | 100 | 100 | — |

9 关中 8 关持平或更优（L5 从 245 降到 106，0.43×）。两个世界模型带着不同假设出发，随共享证据收敛——群体让探索更省动作、对初始假设更不敏感。

### Atari Pong 案例研究：从离散规划到反馈控制

把规划器换成反馈控制器，用学习到的可执行模型预测候选动作后果。同一个"观察-反思-修订-编译-验证"机制：

| 方法 | 类型 | 得分 | 学习成本(帧) |
|------|------|------|------------|
| GDI / LASER | 无模型 RL | 21 | 2.0×10⁸ |
| IMPALA / Rainbow | 无模型 RL | 20.98 / 20.9 | 2.0×10⁸ |
| EfficientZero / V2 | 基于模型 RL | 20.1 / 20.8 | 4.0×10⁵ |
| 人类平均 | 人类 | 14.6 | — |
| 同款 LLM 无世界模型 | 逐帧调用、无记忆 | **-19** | 0 |
| 随机策略 | — | -20.7 | — |
| **Code as Model** | 规则书编译为代码 | **21** | **9.5×10³** |

三个不同开局的对局全部 **21:0** 零封，学习成本只有无模型 RL 的约 1/21000、EfficientZero 的 1/42。更妙的是规则书的修订过程可视化：初始"四带弹跳假设"被一次中路回球证伪 → 修订为居中偏转公式 → 进一步观察发现高估竖直速度，再修订为非对称带状映射（$|v_y| \le 2$）。评估时控制器冻结、**零 LLM 调用**。同款 LLM 不带世界模型只得 -19 分——差距全在"显式可修订的世界模型"。

## 与智能体认知模块的关联

这篇论文对智能体认知架构研究有几条直接的启发：

- **记忆**：规则书是"语义记忆"的教科书式实现——与情景记忆（原始轨迹）分工，且明确"规则级理解必须先入语义层再落到执行层"。Git 记忆更是把记忆组织成**可回溯、可 diff 的学习轨迹**，而不只是覆盖式快照。这为 agent 记忆治理（回滚、召回、防污染）提供了工程范式。
- **世界模型**：把世界模型从神经隐变量搬到"自然语言 + 代码"的显式表示。可检查、可测试、可修订，预测误差直接产生反例。这是对"神经世界模型黑箱"的一次有力对照。
- **推理与规划**：模型条件化最短路规划 + 首个预测失配即停（把新反例纳入后再继续）——规划与学习紧密耦合，而不是一次规划执行到底。
- **元认知**：反思步骤显式区分"规则错了"还是"实现错了"（revise_rulebook vs repair_code），这是元认知监控的最小形式。
- **自我改进**：RSI 不必动参数。把改进对象外置为"世界模型假设"，改进工具就是该假设本身（引导探索、产生证据），递归闭环自然成立。这是**安全的、可审计的自改进**路线。

## 总结与启发

**亮点**：

1. **概念干净**："Code as Model" 双表示 + 版本空间问题的显式处理，是近年来把"世界模型学习"讲得最清楚的工作之一
2. **验证机制扎实**：LLM 语义忠实性判断 + cell-exact 回放的双重门槛，接受标准不依赖 LLM 自信
3. **结果硬核**：ARC-AGI-3 公开集 25 游戏满分、动作效率超人类 2 倍多；Pong 学习成本比 EfficientZero 低 42 倍
4. **工程细节到位**：Git 记忆、跨关卡持久的规则书、群体共享证据同步，都是可直接借鉴的设计

**不足与开放问题**：

- 实验骨干是 Claude Opus 5，且论文自己承认公开集已趋饱和——公开集通关本身无法单独归因于架构贡献，需要 held-out 评估和多次运行稳定性数据
- 规则忠实性判断仍由 LLM 完成，语义层的错误检查并非形式化保证
- 群体扩展只在 N=2、单个游戏上验证，规模化效果未知
- 对非确定性环境的适用性未验证（ARC-AGI-3 和 Pong 都是确定性动力学）

**对后续研究的启发**：把"自改进"的载体从模型参数移到**可检查的外部件**（规则书、代码、技能库），配合执行级验证，可能是一条比权重更新更可控的 RSI 路径。对做 agent 记忆与世界模型的同学，强烈建议读一下第 2 节的形式化和 Figure 5/9 的规则书修订实例——那些"被证伪的假设"如何被优雅地撤回和泛化，正是持续学习最核心的难题。
