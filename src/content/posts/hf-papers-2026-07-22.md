## 研究背景与动机

训练工具使用智能体（tool-use agents）从自身经验中改进，是通向可扩展自进化智能体的核心挑战。现有方法各有瓶颈：

1. **监督微调（SFT）** 依赖固定的教师蒸馏轨迹，性能容易饱和，受限于骨干模型自身能力和轨迹多样性
2. **稀疏奖励强化学习（RL）** 只有最终结果奖励，无法指导中间环节的失败来源——是查询构造问题、工具选择问题、证据提取问题，还是答案综合问题？
3. **在线策略自蒸馏（OPSD）** 需要在每个工具调用步骤提供细粒度的教师分布，但在长周期智能体交互中，这种分布往往噪声很大、不可靠

核心问题可以概括为：**现有自进化管线受限于静态模仿信号、稀疏结果奖励或不可靠的密集监督，而长周期智能体需要一个可验证的环境来提供过程级监督。**

## 核心方法与创新点

### DeepSearch-World：确定性可验证环境

作者构建了一个基于 Wikipedia 的离线确定性环境，核心设计包括：

**数据构建：** 从 Wikipedia 超链接图 $G = (V, E)$ 中采样实体级随机游走 $\tau = (v_1, \ldots, v_H)$，每个节点对应一个目标实体，游走定义了一条 $H$ 跳推理链。通过混淆显式实体提及，构造了 **420K** 多跳 QA 任务，要求智能体通过推理、查询修正和证据发现来恢复目标实体。

**离线工具：** 提供两个与真实网络工具对齐的离线工具：
- `web_search_wiki(x)`：基于 BM25 的确定性检索函数，返回页面标题、摘要和 URL，模拟搜索引擎
- `visit_wiki(u)`：通过 SQLite 索引读取完整文章，模拟浏览器访问

**环境反射机制：** 对每个问题 $q_i$，环境维护真实实体集合 $T_i = \{e_{i,1}, \ldots, e_{i,H}\}$ 进行过程级验证。工具响应若匹配到未解决实体则判定成功，并触发分层规则化反射——首次失败给出通用修正信号，重复失败则揭示更强引导（如规范实体名）。这产生了可验证的"搜索-失败-反思-重试"轨迹。

### 脚手架教师智能体

教师智能体采用三阶段结构：

1. **Plan（规划）：** 初始化结构化进度状态 $s_0$，包含四个可写字段：`completed_list`（已确认子目标）、`todo_list`（待办行动）、`experience`（失败经验）、`information`（已提取证据）
2. **Act（执行）：** 执行最多 $T_{max}$ 步交互，每步选择工具调用 $a_t$，接收观察 $o_t$，并更新状态 $s_{t+1} = U(s_t, a_t, o_t, r_t)$，其中 $r_t$ 是环境反射信号
3. **End（结束）：** 当证据充分或预算耗尽，基于已验证的工作记忆生成最终答案

关键创新在于 **Scaffold-to-ReAct 转换**：脚手架轨迹被转换为标准 ReAct 格式监督，将规划、记忆追踪、反思和错误恢复注入学生模型的推理过程中，而不依赖外部规划或反思提示。

### 自进化训练循环（DeepSearch-Evolve）

在第 $R$ 轮迭代中：

1. **轨迹生成：** 当前模型 $\pi_{\theta_R}$ 在可验证环境中生成脚手架轨迹
2. **拒绝采样与质量过滤：** 保留答案正确的轨迹，并用 LLM 进行轨迹级过滤，去除冗余证据、弱目标对齐和不一致推理
3. **Scaffold-to-ReAct 转换：** 移除阶段特定提示，将进度状态和反思重写为助手推理痕迹
4. **SFT 更新：** 在环境验证的 ReAct 轨迹上进行微调

SFT 损失函数为：

$$\mathcal{L}_{SFT}(\theta) = \mathbb{E}_{\tilde{\tau} \sim \mathcal{D}_e(R)} \left[ \sum_{t=1}^{T} \text{KL}\left(\delta_{y_t} \| \pi_\theta(\cdot | x, y_{<t})\right) \right]$$

与在线策略自蒸馏（OPSD）的区别在于：SFT 使用验证过的离线前缀和硬目标，而 OPSD 使用在线前缀和软目标。选择 evolving SFT 而非完全在线监督，是因为长周期工具使用中完全在线分布监督代价高昂且不可靠。

**重要性采样：** 由于异步生成和训练，使用衰减因子 $\gamma = 0.5$ 跨轮次采样，优先使用最近的验证数据，同时保留早期轨迹以缓解灾难性遗忘。

## 实验结果与分析

### 主要结果

在 Qwen3.5-9B 基础上训练 11 轮自进化后，DeepSearch-World-9B 的表现：

| 基准 | Qwen3.5-9B-Instruct | DeepSearch-World-9B | 提升 |
|------|---------------------|---------------------|------|
| BrowseComp | 7.4 | 31.2 | **+23.8** |
| BrowseComp-ZH | 13.5 | 36.4 | **+22.9** |
| HLE | 20.0 | 49.0 | **+29.0** |
| GAIA | 23.9 | 61.5 | **+37.6** |
| xbench | 45.3 | 93.4 | **+48.1** |
| HotpotQA | - | 93.4 | - |

值得注意的是，DeepSearch-World-9B **不依赖更强模型的蒸馏**，仅从自身环境验证的轨迹中学习，却达到了与开源智能体相当的竞争力。

### 工具使用行为分析

对比 Qwen3.5-9B-Instruct，DeepSearch-World-9B 展现出显著不同的工具使用模式：

- **交互轮次：** 平均 18.0 轮 vs 4.7 轮——不再过早给出最终答案
- **页面访问：** 平均 5.4 次 visit 调用 vs 0.9 次——更强的文档级证据验证
- **高级能力评分：** 在规划、记忆维护、反思、错误恢复和证据综合五个维度上全面提升

### 数据规模效应

420K 任务池 vs 100K 任务池的对比显示：
- 更大的任务池在后续轮次中提供足够未见实例，避免重复暴露导致的过拟合
- 420K 设置达到更高的验证平台期、更低的残余格式错误率、更稳定的工具成功率和实体命中率
- 100K 设置早期改善但更早饱和且波动更大

## 与智能体认知模块的关联

这篇论文对智能体认知架构研究有几层重要启发：

### 1. 进程级认知行为的可验证训练

DeepSearch-World 最核心的贡献在于将智能体的认知行为（规划、记忆追踪、反思、错误恢复）转化为可验证的训练信号。传统方法只能通过结果奖励间接塑造这些行为，而本文通过环境级实体验证提供了直接的过程监督。这为训练更复杂的认知行为（如自我监控、策略调整）提供了可扩展的范式。

### 2. 脚手架到 ReAct 的知识蒸馏

三阶段脚手架教师（Plan-Act-End）本质上是一个具有显式工作记忆和反思机制的认知架构。通过 Scaffold-to-ReAct 转换，这些认知能力被"压缩"进标准 ReAct 模型的推理痕迹中。这提示我们：**复杂认知架构的能力可以通过适当的知识蒸馏方法迁移到更简洁的推理框架中。**

### 3. 自进化中的认知行为涌现

实验显示，随着训练轮次增加，智能体的交互轮次从 4.7 增长到 18.0，visit 调用从 0.9 增长到 5.4。这意味着认知行为（如主动验证、失败后重试）是在自进化过程中逐渐涌现的，而非被显式编程。这为理解认知能力如何从经验中自发习得提供了实证视角。

### 4. 确定性环境作为认知训练场

DeepSearch-World 的设计思路——构建确定性、可验证的离线环境来训练认知能力——可以推广到其他领域。例如，在代码生成、数学推理、甚至具身智能体训练中，类似的可验证环境设计可以提供过程级监督信号。

## 总结与启发

### 亮点

1. **环境设计的巧妙：** 将 Wikipedia 超链接图转化为可验证的多跳推理环境，既保持了与真实网络工具的 schema 对齐，又提供了确定性的过程级验证
2. **自蒸馏范式的创新：** 不依赖更强模型，仅从自身验证轨迹中迭代改进，证明了确定性环境验证可以替代传统教师蒸馏
3. **认知行为的系统化训练：** 将规划、记忆、反思、错误恢复等认知行为统一纳入训练框架，而非作为独立模块
4. **工程上的可扩展性：** 异步生成与训练、重要性采样、数据池规模控制等设计使框架在实际中可用

### 不足

1. **环境局限性：** 仅基于 Wikipedia，与真实网络环境存在分布差距。虽然最后用 GRPO 在真实工具上做了少量微调（1,600 实例），但离线到在线的迁移效果仍需更多验证
2. **任务类型单一：** 主要是多跳 QA，对其他类型的搜索任务（如开放域摘要、对比分析、时效性查询）的泛化能力未知
3. **计算成本：** 11 轮自进化训练，每轮生成 10,000 条轨迹并筛选 4,000 条，计算开销不低
4. **跨语言能力有限：** 训练仅使用英文轨迹，中文基准提升相对较小

### 启发

这篇论文最值得借鉴的思路是：**与其在不可靠的在线环境中摸索，不如构建一个确定性的"认知训练场"。** 对于智能体认知架构研究者来说，这意味着我们可以在受控环境中系统地训练和评估认知能力，然后再迁移到开放世界。这种"先在沙盒中练好基本功，再上真实战场"的策略，可能比直接在复杂环境中做 RL 更高效、更稳定。
