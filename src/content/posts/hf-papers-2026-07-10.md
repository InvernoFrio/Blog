# LaMem-VLA: Dual Latent Memory in Vision-Language-Action Models for Robotic Manipulation

**论文链接：** [Hugging Face](https://huggingface.co/papers/2607.07608) · [arXiv](https://arxiv.org/abs/2607.07608)

**机构：** 南京理工大学、浙江大学、新加坡国立大学

**作者：** Hongyu Qu, Jianzhe Gao, Xiaobin Hu, Shaohuan Yang, Xinlei Yu, Rui Yan, Wenguan Wang, Xiangbo Shu, Shuicheng Yan

---

## 研究背景与动机

当前主流的视觉-语言-动作（VLA）模型，如 OpenVLA、π₀、CogACT，在机器人操作领域取得了令人瞩目的进展。它们将视觉观察和语言指令映射为可执行的动作序列，是具身智能的重要范式。

但这些模型存在一个根本性缺陷：**马尔可夫假设**——它们仅根据当前观察预测动作，完全忽略了时间依赖性。这导致了所谓的"时间短视偏差"（temporal short-horizon bias）：模型能对当前可见状态做出反应，却无法推理之前的状态转移、已完成的操作步骤、以及当前处于多步任务的哪个阶段。

为解决这一问题，已有工作沿两条路线探索：

1. **扩展观察窗口**：拼接历史帧或扩展为视频序列。但计算成本随上下文长度线性增长，且固定窗口构成了硬性记忆上限——窗口外的关键信息会被丢弃。
2. **外部记忆库检索**：将历史轨迹存入外部记忆库，检索后作为辅助上下文注入策略。但记忆存储在模型原生 token 空间之外，被当作"外挂"使用，无法与模型内部的多模态推理过程自然交织。

这引出了一个更根本的问题：**历史经验能否被表示为上下文原生的记忆，在 VLA 模型进行感知、推理和行动的同一连续空间中被存储、检索和消费？**

---

## 核心方法与创新点

LaMem-VLA 给出了肯定的回答。其核心思想是：将历史经验重构为**潜变量记忆 token**（latent memory tokens），直接编织进 VLA 模型的推理序列中，使记忆成为模型运行上下文的一部分，而非附加的脚手架。

### 四大协调模块

LaMem-VLA 由四个紧密协作的模块构成：

#### 1. 策展器（Curator）♣

将历史经验分解为两个互补的记忆库：

- **短期记忆库**：以视觉为主导，保存当前 episode 中的近期视觉证据（如物体位置、细微状态变化）
- **长期记忆库**：以语义为主导，保存任务进度、上下文语义和跨较长时间跨度的动作连续性

两者的区别在于**来源和功能**，而非表示形式——最终都被重建为潜变量记忆 token。

#### 2. 寻找器（Seeker）♠

在动作推理过程中，从当前多模态认知状态（视觉和指令 token）构建上下文感知的查询向量，用于从双记忆库中检索与任务相关的历史证据。这使得当前决策能够"锚定"在过去的感知证据和长程语义-动作连续性上。

#### 3. 压缩器（Condenser）♥

将检索到的（可能冗余的）证据压缩为固定长度的短期和长期潜变量记忆 token，使其与 VLA 模型的嵌入空间兼容。

#### 4. 编织器（Weaver）♠

将压缩后的记忆 token 直接缝合进动作推理序列中，位于动作查询 token 之前。这使得历史记忆能够参与到与当前图像、指令和动作查询相同的潜变量推理过程中。

### 关键公式化表达

设 VLA 模型的推理序列为：

$$S = [v_1, \ldots, v_n, l_1, \ldots, l_m, a_1, \ldots, a_k]$$

其中 $v_i$ 为视觉 token，$l_j$ 为语言 token，$a_t$ 为动作查询 token。

LaMem-VLA 将记忆 token 编织进该序列：

$$S' = [v_1, \ldots, v_n, l_1, \ldots, l_m, \mathbf{m}_{st}, \mathbf{m}_{lt}, a_1, \ldots, a_k]$$

其中 $\mathbf{m}_{st}$ 和 $\mathbf{m}_{lt}$ 分别为压缩后的短期和长期潜变量记忆 token。记忆 token 与视觉/语言 token 在同一嵌入空间中，参与相同的 Transformer 自注意力计算。

最终，记忆锚定的动作查询通过基于扩散的动作专家（diffusion-based action expert）生成时间感知的机器人动作序列。

### 与现有范式的本质区别

| 维度 | 传统方法 | LaMem-VLA |
|------|---------|-----------|
| 记忆存储 | 外部记忆库 / 扩展观察窗口 | 模型原生嵌入空间 |
| 记忆消费 | 推理后作为辅助上下文 | 推理中直接参与 |
| 记忆与推理的关系 | 前后分离 | 同空间交织 |
| 记忆形式 | 原始帧 / 稀疏抽象 | 潜变量 token |

## 实验结果与分析

### 实验设置

在两个模拟器上进行评估：
- **LIBERO**：包含 4 个套件（Libero-Spatial、Libero-Object、Libero-Goal、Libero-Long），涵盖从空间推理到长程操作的多种任务
- **SimplerEnv-Bridge**：桥接仿真与真实世界的操作任务

### 主要结果

**LIBERO 基准：**

| 方法 | Spatial | Object | Goal | Long | 平均 |
|------|---------|--------|------|------|------|
| CogACT (baseline) | 92.3 | 91.8 | 88.7 | 85.8 | 93.2 |
| MemoryVLA | 96.3 | 97.5 | 96.3 | 95.5 | 96.5 |
| **LaMem-VLA** | **98.0** | **98.3** | **97.5** | **96.8** | **97.6** |

- 超越 baseline CogACT **4.4 个百分点**
- 超越 MemoryVLA **1.1 个百分点**
- 超越 π₀ **3.5 个百分点**（前四个套件）

**SimplerEnv-Bridge 基准：**

LaMem-VLA 达到 **73.9%** 平均成功率，超越 CogACT **16.6 个百分点**，超越 π₀ **4.7 个百分点**。

### 关键分析

1. **长程任务收益最大**：在 Libero-Long 套件上，LaMem-VLA 相比 baseline 提升最为显著，验证了潜变量记忆对长程任务的关键价值。
2. **记忆编织 vs 记忆拼接**：消融实验表明，将记忆 token 编织进推理序列（而非简单拼接在序列末尾）能带来更显著的性能提升，说明记忆参与推理过程的方式至关重要。
3. **双记忆库互补性**：短期记忆库和长期记忆库各自贡献不可替代——短期记忆对视觉状态变化敏感，长期记忆对任务进度和语义连续性敏感。

## 与智能体认知模块的关联

LaMem-VLA 的贡献远超机器人操作本身，对智能体认知架构研究有深刻启发：

### 1. 记忆的"原生性"原则

论文提出的核心洞察——记忆应该在模型的原生嵌入空间中被存储、检索和消费——是认知架构设计的一个重要原则。当前许多智能体的记忆系统（如 RAG）本质上是"外挂式"的：记忆检索和推理是两个分离的过程。LaMem-VLA 暗示，**记忆与推理的融合深度决定了记忆的有效性**。

这对 LLM 智能体的记忆设计有直接启示：与其将检索到的上下文简单拼接到 prompt 中，不如探索如何将历史经验编码为模型内部空间的表示，使其参与注意力计算。

### 2. 双记忆系统

短期记忆（视觉主导）和长期记忆（语义主导）的双系统设计，与认知科学中的工作记忆/长期记忆区分高度一致。这提示智能体架构设计者：**不同类型的历史经验需要不同的编码和检索机制**，而非一刀切的统一记忆库。

### 3. 潜变量推理的潜力

LaMem-VLA 将记忆编码为潜变量 token 而非自然语言，这与近期"潜变量推理"（latent reasoning）的趋势一致。这暗示了一个方向：**智能体的内部推理不必局限于自然语言空间**，潜变量空间可能提供更高效的推理通道。

### 4. 从马尔可夫到非马尔可夫

论文清晰地论证了马尔可夫假设在长程任务中的局限性。对智能体研究而言，这意味着：**任何需要跨多步决策的智能体架构都必须突破马尔可夫假设**，无论是通过记忆机制、世界模型、还是其他方式。

---

## 总结与启发

### 亮点

1. **范式创新**：提出"上下文原生潜变量记忆"范式，将记忆从"外挂"提升为"内生"，这是记忆增强 VLA 模型的一个重要概念性突破。
2. **架构优雅**：四个模块（Curator、Seeker、Condenser、Weaver）分工明确、协作紧密，形成了从记忆组织到记忆消费的完整闭环。
3. **实验扎实**：在多个基准上取得 SOTA，尤其在长程任务上收益显著，验证了方法的有效性。
4. **认知启发**：双记忆系统设计与认知科学高度一致，为智能体架构提供了有据可循的设计原则。

### 不足

1. **仅仿真验证**：当前实验仅在模拟环境中进行，作者表示正在扩展到真实机器人平台。
2. **记忆更新机制**：论文未详细讨论记忆库的动态更新策略——当任务场景变化时，如何淘汰过时的记忆？
3. **计算开销**：虽然论文声称在有界上下文内工作，但记忆检索和压缩的额外计算成本未被充分讨论。
4. **泛化性**：当前验证局限于桌面操作任务，在更开放的场景（如导航、社交交互）中的表现有待验证。

### 对未来研究的启发

LaMem-VLA 暗示了一条值得探索的路径：**将智能体的所有认知模块（感知、记忆、推理、规划、行动）统一在同一潜变量空间中**，而非让它们各自为政。如果记忆可以在模型的原生空间中运作，那么规划和推理是否也可以？这可能导向一种更统一、更高效的智能体认知架构。
