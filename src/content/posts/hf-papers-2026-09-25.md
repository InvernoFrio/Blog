# Agent-Editing World Model: Rethinking World Modeling for LLM Agents

> **论文链接**: [arXiv:2609.28416](https://arxiv.org/abs/2609.28416)
> **机构**: 中国人民大学高瓴人工智能学院
> **作者**: Shuang Sun, Guoxin Chen, Fanzhe Meng, Jia Deng, Huatong Song, Jinhao Jiang, Wayne Xin Zhao, Hongteng Xu, Ji-Rong Wen
> **日期**: 2026-09-23

## 研究背景与动机

世界模型（World Model）被广泛视为通用智能的基础——它捕捉世界的结构和动态，支撑理解、推理和规划。在 LLM 智能体领域，现有的语言世界模型大多沿用"预测下一观测"的范式：给定当前状态和动作，预测环境会返回什么（比如 API 输出、终端结果、搜索结果）。

但论文指出了一个根本性问题：**任务导向的 LLM 智能体需要环境反馈来解决任务，而不是重建环境。** 搜索结果依赖不断变化的网页内容和不透明的排名算法；终端输出和测试结果依赖文件系统和运行时状态。这些观测本质上是**高熵的、执行依赖的**——预测它们既困难，又在真实工具已经能提供可靠反馈的情况下价值有限。更糟的是，模拟还可能引入虚假证据，反而干扰智能体的判断。

与此同时，论文发现了一个被忽视的失败机制：**任务状态污染（task-state contamination）**。智能体在探索未知环境时需要维护假设、计划和对已验证进展的判断，但实际上它们常常：

- 把未经验证的假设当作事实
- 尽管收到矛盾反馈，仍然保留过时的计划
- 把部分进展误认为任务完成

这些错误会留在历史记录中，通过局部看似合理的动作不断累积放大。**即使有真实的环境观测，智能体的理解也不一定能正确更新。**

核心问题由此变成：**语言世界模型应该预测什么，才能可靠地支持长程智能体？**

## 核心方法与创新点

### AEWM：从观测预测到智能体状态编辑

AEWM（Agent-Editing World Model）给出了一个全新的答案：**不预测环境观测，而是建模推理和行动如何塑造未来的任务进展，并在执行前编辑可能传播污染的推理-行动延续。**

形式化地，给定任务 $x$，交互历史 $h_t = (x, (r_i, a_i, o_i)_{i=0}^{t-1})$，智能体提出推理-行动对 $(\hat{r}_t, \hat{a}_t)$，形成执行前状态 $s_t = h_t \oplus (\hat{r}_t, \hat{a}_t)$。

传统世界模型学习 $\mathcal{M}_{obs}(o_t | s_t)$——预测观测。而 AEWM 学习的是决策效果和状态干预：

$$s_t \xrightarrow{\mathcal{M}_{obs}} \hat{o}_t \quad \text{(传统: 观测预测)} \qquad \text{vs.} \qquad s_t \xrightarrow{\mathcal{M}_{SR}} \tilde{s}_t = h_t \oplus (\tilde{r}_t, \tilde{a}_t) \quad \text{(AEWM: 状态编辑)}$$

### Action Judge：三分类决策判断

Action Judge 在动作执行之前，对当前推理-行动对进行效果预测，输出三分类标签：

| 类别 | 含义 | 示例 |
|------|------|------|
| **Critical** | 关闭关键缺口、获取必要证据、执行必需的状态变更 | 找到正确的 API 参数并调用 |
| **Exploratory** | 有意义地降低不确定性或测试合理分支 | 搜索候选方案、查看文档 |
| **Noisy** | 预期进展很少，促进重复、无关、违反约束或错误方向 | 反复查看已知信息、在错误路径上继续深入 |

关键设计是显式保留 **Exploratory** 类——不是所有非关键动作都是噪声，信息收集本身是有价值的。判断基于 $s_t$ 在执行前做出，不需要先运行动作看结果。

### State Revision：编辑噪声推理-行动延续

对被判为 Noisy 的决策，State Revision 生成修正后的 $(\tilde{r}_t, \tilde{a}_t) \sim \mathcal{M}_{SR}(\cdot | s_t)$：

- **修正推理**：调和矛盾信息、修正无根据的假设、更新计划
- **修正行动**：将纠正转化为下一步交互；当证据不足时，通过真实环境交互获取证据

与仅提供"建议"或"批评"不同，AEWM **直接改变后续历史中携带的状态**——编辑后的推理-行动对会成为后续历史的一部分，从根本上阻断污染传播。

### EditAct：编辑与执行的整合

EditAct 将判断和修正整合到智能体推理流程中：

1. 保留有成效的决策
2. 修正噪声决策
3. 在真实环境中执行选定的动作
4. 选定的推理-行动对和真实观测一起进入后续历史

### 训练框架

- **数据合成**：标注智能体通过轮次级标注合成 Action Judge 数据；提议和修正智能体联合构建 State Revision 样本
- **两阶段训练**：Mid-training（52B tokens，学习交互知识）+ SFT（120K 精选样本，激活和校准判断与修正能力）
- **跨领域覆盖**：Search、Terminal、SWE 三个领域

### AEWM-RFT：将编辑能力蒸馏回智能体

论文还提出了 AEWM-RFT：用验证过的 EditAct 轨迹做拒绝采样微调（RFT），将 AEWM 引导的决策模式迁移到智能体参数中。**推理时不需要 AEWM**，纯靠微调就能获得收益。

## 实验结果与分析

### Action Judge 基准

论文构建了 3,000 决策的跨领域 Action Judge 基准：

| 方法 | Macro-F1 |
|------|----------|
| 最强前沿基线 | 59.9% |
| **AEWM** | **70.5%** |

超出最强基线 **10.6 个百分点**。

### EditAct 六基准三骨干

| 骨干模型 | 平均提升（vs 最强基线） |
|----------|----------------------|
| Qwen3.5-4B | +6.7 分 |
| Qwen3.5-9B | +5.2 分 |
| Qwen3.5-35B-A3B | +3.2 分 |

在全部六个基准、三个骨干上，EditAct 一致超越 ReAct 以及步级和轨迹级 Best@3。

### AEWM-RFT 迁移效果

| 方法 | 三领域平均 |
|------|-----------|
| Self-RFT | 基线 |
| **AEWM-RFT** | **+2.2 ~ +2.6 分** |

无需在线 AEWM 引导即可获得提升，证明编辑后的轨迹包含可迁移的决策知识。

### 关键消融发现

EditAct **超越了智能体重采样和推理提示**——直接替换当前推理-行动延续比"给出建议让智能体重新生成"更有效。这支持了"状态编辑 > 批评引导"的设计哲学。

## 与智能体认知模块的关联

这篇论文对智能体认知架构研究有深刻的启发：

### 1. 世界模型的角色重定义

传统观点认为世界模型 = 环境模拟器。AEWM 证明：**世界模型更应该建模"智能体的理解如何演变"而非"环境如何回应"**。这对智能体架构设计意味着，世界模型模块的职责应该从"预测外部"转向"监控内部"。

### 2. 任务状态污染是智能体的系统性风险

论文命名的"任务状态污染"现象——假设固化、计划过时、进展误判——在长程任务中普遍存在。这对智能体记忆系统设计有直接启发：**记忆不仅要存储事实，还要维护"哪些假设已验证、哪些计划已过时"的元信息**，并具备主动清理污染的能力。

### 3. 决策分类是高效推理的基础

Action Judge 的三分类（Critical / Exploratory / Noisy）提供了一个实用的决策质量评估框架。这与我们之前讨论的"决策品味"（Taste）概念高度互补——品味关注"分叉点选哪个方向"，Action Judge 关注"当前决策属于哪类"，两者共同构成对智能体决策过程的更完整理解。

### 4. 状态编辑 vs 轨迹重生成

消融实验表明，直接编辑当前状态比让智能体重新生成更有效。这启示我们：**当检测到智能体犯错时，精确修复错误比推倒重来更高效**——无论是对推理链、记忆状态还是执行计划。

### 5. 可迁移的决策蒸馏

AEWM-RFT 证明，编辑后的轨迹可以蒸馏为智能体的内在能力。这意味着**世界模型可以作为"教师"，通过轨迹编辑生成高质量训练信号，提升智能体的决策质量而无需在线指导**。

## 总结与启发

**亮点**：

1. **视角转换精准**：从"预测环境"到"编辑智能体状态"，切入点新颖且有充分的动机论证
2. **任务状态污染的命名和分析**：为智能体长程任务中的常见失败模式提供了清晰的概念框架
3. **训练框架完整**：数据合成 → 两阶段训练 → 跨领域验证 → RFT 迁移，闭环设计
4. **实验扎实**：Action Judge 超基线 10.6 F1，EditAct 六基准三骨干一致提升，消融验证了核心设计选择

**不足**：

1. 依赖合成数据训练 Action Judge 和 State Revision，标注质量的上限决定了模型能力的上限
2. 三分类虽然实用，但真实场景中决策质量可能是连续谱
3. AEWM-RFT 的迁移效果虽然显著，但绝对分数仍有较大提升空间

**对后续研究的启发**：

- **"编辑"作为一种新的世界模型范式**值得深入探索——不只是预测或模拟，而是主动干预智能体状态
- **任务状态污染**可能成为智能体可靠性研究的重要课题，值得系统性地度量和治理
- **决策判断 + 状态修正**的组合可以推广到更多智能体架构中，作为通用的"质量守门员"

这篇论文最深刻的启示或许是：**好的世界模型不一定要精确模拟外部世界，更重要的是帮助智能体正确理解自己所处的状态。** 内省比预测更关键。
