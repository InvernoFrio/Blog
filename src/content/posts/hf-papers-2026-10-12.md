## 研究背景与动机

智能体进入陌生环境，要学的不只是"哪些动作有用"，更是"我的动作到底做了什么"。基于模型（model-based）的智能体先学一个世界模型，用它预测动作后果再决策。**程序**是这类模型很有吸引力的表示：状态转移和目标条件写成可执行函数，规划器可以反复查询，预测与观察的偏差还能给模型提供具体的反例。WorldCoder、GIF-MCTS、Code-as-World 等近期工作已经展示了"从交互中学出代码世界模型"的可行性。

但作者指出了一个更本质的问题：**与已有观察一致，不等于泛化正确**。有限的交互历史通常留下一个"版本空间"（version space）——多个程序都能复现已观察到的所有转移，却在未观察状态上给出不同预测。论文举了个漂亮的例子：如果所有观察到的墙都在第 7 列，那么"箱子撞墙停"和"箱子到第 7 列停"这两条假设能解释同一条轨迹，但当墙出现在别处时预测完全不同。精确回放（replay）可以**否决**不一致的程序，却无法在一致的候选中**识别**哪条规则是对的。智能体必须显式维护并修订自己的泛化假设。

这正好对应认知科学里的"理论更替"：证据不足以在多个世界模型之间做区分时，智能体需要一个**可修订的假设载体**。而 Memento 系列的主线恰好是"把外部记忆而非模型参数当作学习状态"：

- **Memento**：情景记忆，把交互结果写入记忆、检索来改进决策（改进**策略侧**）；
- **Memento 2**：把记忆写入形式化为策略评估、记忆读取形式化为策略改进（状态化反思学习）；
- **Memento-Skills**：把学习状态扩展到可复用的程序性记忆（技能）；
- **Memento 3**（本文）：把反思学习从"策略/程序"扩展到**显式世界模型**——学习"世界如何运转"的**模型侧**。

作者的核心设计叫 **Code as Model**：自然语言规则书 ψ 是持久语义记忆（记录对物体、动作语义、动力学、目标、未决备选的假设），编译出的可执行程序 θ 是它的执行实现，二者构成持久的世界模型假设 h = (ψ, θ)。规则书负责"规则级"的理解与修订，代码负责"如何应用规则"——理解变了必须先改规则书再编译；纯粹的实现 bug 则只改代码不动规则书。这个分工是全文的方法论支点。

## 核心方法与创新点

### 1. 问题形式化：Bayes-adaptive POMDP 中的外部学习状态

环境建模为确定性的目标导向 POMDP：M = ⟨S, A, O, T, ρ, G⟩，转移函数 T 和目标集 G 对智能体**未知**（无源码、无自然语言任务描述，只报告完成信号）。智能体的外部学习状态是三元组：

**Z_t = (H_t, ψ_t, θ_t)**

其中 H_t 是动作-观察历史（情景证据），ψ_t 是规则书（语义记忆/假设），θ_t 是可执行实现。注意第 (5) 式明确写出 **φ_{t+1} = φ_t = φ**——LLM 参数全程冻结，"改进"完全发生在外部记忆里。这正是 Memento 系列对 RSI 的重新定义：不是让模型改自己的权重，而是让智能体**修订支撑其推理、规划、学习的组件**（此处即世界模型假设 h_t），修订后的组件反过来指导后续交互、塑造下一轮修订所需的证据。论文称之为**模型侧递归自改进（Model-based RSI）**。

### 2. 五阶段反思循环：观察 → 反思 → 规则修订 → 编译 → 验证

每一步真实动作后，外部状态经五个阶段更新：

1. **观察**：执行 θ_t 得到预测，与真实观察 o_t 对比，扩展记录 H_t；
2. **反思**：冻结 LLM 从 {保留、改规则书、只修代码} 中选择修订类型——预测不匹配可能源于**规则错了**，也可能源于**代码没实现对规则**，这个归因本身就是元认知判断；
3. **规则修订**：LLM 的修订算子产出新规则书 ψ'（可以改实体、状态变量、转移规则、目标条件；对未观察到的机制**留白不写死**）；
4. **编译**：规则书引导的编译器从 (旧代码, 新规则书, 记录) 产出新可执行 θ'，包含内部状态初始化 ι、转移预测 f、观察函数 ρ_θ、目标集 Ĝ_θ；
5. **验证**：双门槛准入——(a) **规则书保真**（LLM 语义判断代码确实实现了规则书）＋ (b) **逐格精确回放**（把历史动作序列在模拟器里重放，预测的每一帧每个格子都必须与记录一致）。两条都过才接受，否则打回反思重来。

这里有个值得注意的设计哲学：**准入不依赖 LLM 的置信度打分，而是"语义判断 + 精确执行"组合**。论文引用 Hypothesis Search 的结论：单纯按语言模型排序筛候选会把正确答案排掉，所以只要后果可观察，就用执行来落地验证。而且每次新提案都要对**整个历史**回放——修补必须同时解释旧证据和新偏差，防止"头痛医头"式的局部补丁。

### 3. 模型选择与规划：MDL 偏置 + 最短路执行

验证通过后可能仍剩多个一致假设（version space 没被消完）。单模型模式下，LLM 在通过验证的候选里**偏好最简洁的规则书和实现**——这是个实用的最小描述长度（MDL）偏置，形式化为：

**min |ψ| + |θ|ψ**（规则书长度 + 给定规则书后代码的条件描述长度）

论文证明这等价于在"规则书保真对"上的 MAP 后验最大化。确定性 + 等动作代价下，规划退化为在可执行模型诱导的内部状态空间上求**最短路**：每步选使剩余距离减一的动作，天然无环；没有可达计划时转入探索——LLM 根据规则书里**未解决的假设**挑一个中间目标（测一个机制、揭开一块迷雾、碰一个没解释的物体），辅助规划器找路，执行中一旦预测与观察不符就停下、把反例送回反思。这个"探索动机直接来自规则书的未决条目"的设计很聪明：它把**认识论上的好奇心**（我想验证哪条假设）落成了可执行的目标选择。

### 4. 群体扩展：对抗"自我证实"的错误模型

单模型有个理论隐患（论文的式 28-29 讲得很清楚）：一个貌似合理但错误的模型，如果它的策略**从未走到能暴露错误的历史**上，E(θ) ∩ R(θ) = ∅，它就永远不被证伪——错误模型可以自我证实。光用自然语言重写假设并不能消除这种行为。于是扩展出 **N 个并行的世界模型假设**（各自一套规则书+代码），共享同一份交互历史，每个规划 episode 轮流采样一个成员出计划，产生的转移证据用来**检验所有成员**，预测冲突者被修复。这本质上是后验采样/ensemble 思想的"规则书版"。N=1 退化为单模型。

### 5. Git 记忆：学习轨迹本身可检索

实现层面有个很妙的工程细节：规则书和代码放进一个 **Git 仓库**，每次迭代 commit 并打标签。于是智能体可以 diff 任意两版规则书、回滚被改坏的代码、检索"我以前测过哪条假设"。记忆不只有"最新快照"，而是**完整的、可寻址的学习轨迹**。对比多数智能体记忆系统只存增量笔记，Git 作为记忆介质提供了版本、来源、时序三重结构，且零额外基础设施。

## 实验结果与分析

### ARC-AGI-3：25 个公开游戏全部通关

ARC-AGI-3 要求智能体在**不知道游戏规则**的情况下推断动作语义与目标，并在人类基准动作预算内通关；计分用 RHAE（相对人类动作效率，100 为上限），所有环境动作（含失败尝试和 reset）都计入。所有基线数字取自各系统官方 ARC Prize scorecard，与人类基线同口径。

**表 1：公开 ARC-AGI-3 游戏平均 RHAE 汇总**（逐局全部为 100.0，此处列汇总）

| 系统 | 平均 RHAE | 通关游戏数 | 通关关卡数（共 183） |
|------|-----------|-----------|---------------------|
| Continual Harness | 20.5 | 3 | 64 |
| DreamTeam | 38.1 | 6 | 98 |
| OPINE-World | 78.4 | 20 | 160 |
| NOOA | 85.1 | 19 | 170 |

逐局看，本文是唯一在**所有 25 局**都拿到 RHAE 100.0 的系统（baseline1 有 tn36 90.1、sc25 84.2 等未到顶）；相对 Claude Opus 5 + ARC Prize 标准 harness 平均高出 **59.3 个 RHAE 点**。

总动作数 7,518，是人类基线的 **0.44 倍**；每局比值从 0.20（m0r0）到 0.67（lf52），中位数约 0.42。唯一同样全通关的 baseline1 用了 8,347 个动作（0.49 倍）。其余四个系统都有未通关游戏，其总动作数反映的是"跑了多少"而非"解决要多少"。

### 消融：规则书到底贡献了什么？

去掉规则书、只留代码世界模型（harness、回放验证器、规划执行器、骨干、推理强度全部逐字节一致），按人类每关动作数分三档各选一局：

**表 3：规则书消融**（全部通关、RHAE 均 100，比收敛成本）

| 游戏 | 难度档 | 人类动作/关 | 动作（有规则书） | 动作（无规则书） | agent turns（有） | agent turns（无） |
|------|-------|-----------|-----------------|-----------------|------------------|------------------|
| ft09 | 易 | 35 | **75** | 79 | **132** | 174 |
| ka59 | 中 | 104 | **341** | 382 | **298** | 310 |
| cn04 | 难 | 132 | **201** | 216 | **248** | 346 |
| 合计 | — | — | **617**（-9%） | 677 | **678**（-18%） | 830 |

三个难度档动作数全部下降，agent 迭代轮数降 18%。也就是说：规则书不改变"能不能做成"，但**加快收敛到有效可执行模型**——语言层的假设记录减少了反复试错。

### 群体扩展：wa30 上 N=2

**表 4：wa30 逐关动作数**（人类基线 1,843）

| 指标 | N=1 | N=2 群体 | N=2 vs N=1 |
|------|-----|---------|-----------|
| 总动作 | 899 | **597** | **0.66×** |
| RHAE | 100 | 100 | — |
| 逐关 | — | 9 关中 8 关持平或更优 | L5 达 0.43×，仅 L8 略升（1.06×） |

两个世界模型从不同假设出发，随共享历史收敛。这支持论文的论点：维护假设群体能让探索更动作高效、更不依赖某一次随机的初始假设。

### Atari Pong：学出的世界模型能做反馈控制

规则书+编译代码的机制不止能做离散规划。在 Pong（ALE，frame-skip 4）上，规划器被换成反馈控制器：每步从最近帧重建状态（拟合球速、对手移动相位），用可执行模型预测候选动作后果后选动作。规则书的修订过程本身就是教科书式的假设更替——初始"四带反弹假设"排除水平回球 → 中心命中回球证伪之，改为居中偏转公式 → 后续接触显示公式高估垂直回速，改为非对称带图。

**表 5：Pong 得分**（回合分 = 己方得分 − 对手得分，满分 21）

| 方法 | 路线 | 得分 | 学习成本（帧） |
|------|------|------|---------------|
| GDI / LASER | 无模型 RL | 21 | 2.0×10⁸ |
| IMPALA | 无模型 RL（分布式） | 20.98 | 2.0×10⁸ |
| Rainbow | 无模型 RL（分布式 DQN） | 20.9 | 2.0×10⁸ |
| EfficientZero | 基于模型 RL（潜动力学+MCTS） | 20.1 | 4.0×10⁵ |
| EfficientZero V2 | 基于模型 RL（潜动力学+树搜索） | 20.8 | 4.0×10⁵ |
| 人类平均 | 人类游玩 | 14.6 | — |
| 同款 LLM 无世界模型 | 每帧一次 LLM 调用，无记忆 | **-19** | 0 |
| 随机策略 | 动作均匀随机 | -20.7 | — |
| **Code as Model（本文）** | 语言规则书编译为代码 | **21** | **9,504** |

三个不同开局的回合全部 **21:0 零封**（分别用 3,358 / 4,014 / 5,039 个动作），学习成本 9,504 帧——约为无模型 RL 基线的 1/21,000、基于模型 RL 基线的 1/42。学习期用 LLM，**评估期控制器完全冻结、零 LLM 调用**。同款 LLM 不带世界模型（每帧调用、无记忆）只得 -19，这个对照很致命：差距不来自 LLM 能力，而来自**显式、可修订、可执行的世界模型**。

## 与智能体认知模块的关联

这篇论文几乎是一份"智能体认知架构"的清单式实现，值得逐条对照：

- **记忆**：规则书 = 持久语义记忆，交互记录 = 情景记忆，Git 仓库 = 可寻址的元记忆（记忆的历史本身可检索）。三者分工清晰，而且"规则级修订先写语言、再编译代码"给出了记忆写入的**准入纪律**——不是所有想法都直接进代码。
- **世界模型**：明确区分"假设"（规则书，允许留白、允许多个竞争假设并存）与"实现"（代码，必须逐格精确回放通过）。这正是认知科学里"心理模型是可修订假说而非感知副本"的工程化。
- **元认知**：反思阶段的三分支归因（保留 / 改规则 / 修代码）本质上是**错误来源诊断**——预测偏差到底是"世界理解错了"还是"实现写错了"？这是智能体元认知里最实用也最少被显式建模的一环。
- **推理与规划**：验证过的可执行模型把规划降级为最短路查询（便宜、可重复、可审计），而"无计划时按规则书未决假设选探索目标"实现了**认识论驱动的探索**——不是随机试，而是为消除假设不确定性而行动。
- **自我改进 / RSI**：把 RSI 从"改参数/改提示词"移到"改外部世界模型"，并给出了可验证的准入条件（保真 + 回放）。递归性体现在：改进后的模型改变探索轨迹，探索轨迹又产生修订模型的证据。

对研究者的直接启发：**可执行 + 可验证 + 可回滚**的三件套（代码实现、逐格回放、Git 版本）可能是冻结 LLM 智能体做长期学习的通用基建；而"多假设群体共享证据"是应对自我证实偏差的低成本手段（N=2 就拿到 0.66× 的动作节省）。

## 总结与启发

**亮点**：

1. **方法论上的诚实**。不做端到端玄学调参，而是把"学习世界模型"拆成语言假设、执行实现、精确验证三层，每层职责明确、可单独消融。消融实验直接证明语言规则书贡献 9% 动作 / 18% 轮数的收敛加速。
2. **验证设计讲究**。LLM 语义保真 + 逐格精确回放的双门槛，明确拒绝"LLM 自信度打分"式准入，与 Hypothesis Search 的教训一致——能执行落地的判断就别交给语言模型拍脑袋。
3. **数字有说服力且口径干净**。ARC-AGI-3 全部 25 局 RHAE 100、动作 0.44 倍人类；Pong 学习成本 9,504 帧对 4×10⁵（基于模型 RL）/ 2×10⁸（无模型 RL），且推理期零 LLM。所有基线取自官方 scorecard 同口径。
4. **Git 记忆**是低成本高回报的工程创新，可直接搬到任何长程智能体的记忆系统里。

**不足与保留**：

1. **骨干并非冻结的开源小模型**：实现用 Claude Opus 5（extra-high reasoning）在 Claude Code 里跑，规则书修订、代码编译、保真判断的"智能"大量来自前沿闭源模型。"LLM 冻结"的形式成立，但能力上限仍由骨干决定，迁移到开源模型的可行性未验证。
2. **环境假设偏友好**：ARC-AGI-3 与 Pong 都是确定性环境。论文自己也说 Pong 的模型"不必恢复全部动力学，只要对决策足够准"。在随机/对抗/部分可观察更强的环境里，逐格精确回放这条准入门槛可能过严（真实的随机性会被当成规则错误去"修"），MDL 偏置和群体扩展能否兜住值得追问。
3. **成本与规模**：每个 ARC-AGI-3 run 的时间和金钱成本"substantial"，消融只敢做 3 局、群体实验只敢做 1 局 N=2。收敛加速的结论建立在小样本上。
4. **无公开代码**，复现门槛高；"可执行世界模型要求"是否普遍有益，社区已有相反证据（baseline1 的后续组件研究发现可执行模型并不总是提升动作表现，论文自己在相关工作里引了），本文的确定性场景恰好是它的主场。

**对后续研究的启发**：把"世界模型"当作**带版本控制的活文档**而不是训练产物——用语言承载假设、用代码承载执行、用回放承载裁决、用 Git 承载历史，这四件事拼起来就是一套可审计的智能体认知基建。下一步自然的问题是：随机环境下的"软回放"准入（统计一致性替代逐格一致）、群体规模 N 的收益曲线、以及把这套机制搬到真实具身/多智能体场景时，规则书的组合爆炸怎么治理。
